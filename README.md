# 抗癌搭子（cancer-buddy）

[English](README_EN.md) · [安装](INSTALL.md) · [更新记录](CHANGELOG.md) · [参与贡献](CONTRIBUTING.md)

抗癌搭子是一组给 AI 助手（如 Claude Code）用的 skill，帮癌症患者和家属：

- 把手机里、纸袋里的一堆病历整理成一份**能追溯到原件**的档案；
- 在档案之上**看懂报告**、准备看病要问的问题、画化验趋势图；
- 找医院和临床试验、查饮食和保健品、和家人沟通、准备第二意见、安全地分享病历。

它会把"一般是怎么回事、指南一般怎么说"讲清楚，并注明来源；对"我这个情况该怎么治"这类个人判断，它会帮你整理好问题，交给你的主诊医生。

## 能做什么

| 模块 | 做什么 |
|---|---|
| `cancer-buddy` | 总入口：判断你要做什么，交给对应模块；共用的规则和脚本（必须安装） |
| `cancer-buddy-organize` | 整理病历：拍照、PDF、压缩包都行，逐页转写、归类、生成一页纸病情总结 |
| `cancer-buddy-visit-prep` | 就诊准备包：医生 30 秒速览、要问的问题、要带的东西 |
| `cancer-buddy-charts` | 把化验、肿瘤标志物、体重画成趋势图 |
| `cancer-buddy-education` | 用大白话解释报告和治疗；副作用和对症用药的一般知识 |
| `cancer-buddy-nutrition` | 按症状调整饮食、食品安全、保健品和药的相互作用核查、各地家常菜替换 |
| `cancer-buddy-caregiver` | 陪诊核对单、家庭分工、怎么跟孩子说、照护者减负 |
| `cancer-buddy-disclosure` | 要不要告诉、怎么开口、家里意见不一怎么办 |
| `cancer-buddy-find-care` | 找医院、医生、MDT、临床试验站点（不排名，每条带官方来源） |
| `cancer-buddy-case-precedent` | 查已发表的类似病例报告 |
| `cancer-buddy-second-opinion` | 准备第二意见资料包、病理切片借寄 |
| `cancer-buddy-vault` | 看档案里有什么、按目的导出、记录和撤回授权 |
| `web-access` | 联网检索的底层工具（第三方，原样收录） |

## 安装

```bash
npx skills add CancerDAO/cancer-buddy-skill -g --all
```

需要 Python 3.9 或以上。详细要求见 [INSTALL.md](INSTALL.md)。

## 你的资料放在哪里、谁能看到

- 档案存在**你自己的电脑上**，默认在 `~/CancerDAO/patients/PT-XXXXXXXXXX/`（可用环境变量 `CANCER_BUDDY_PATIENTS_DIR` 改位置）。`PT-` 后面是随机编号，和姓名无关。
- 原件原样保存在档案的 `raw/` 文件夹里，永远不会被改动或删除；你给的原始文件夹也不会被删除。
- 整理出来的文字稿里，姓名、证件号、电话、住址、病案号会被替换成 `[姓名]` 这样的标记。医院名、日期和全部医学内容照原样保留。真实的姓名等信息只记在受控的 `raw/` 文件夹里（包括上传时的原始文件名），用来在整理结束和导出前自动复查；它们不会进入整理结果，也不会被导出。
- 整理和问答时，病历内容会发送给你所用的 AI 服务来阅读，这一点和你平时把病历发给 AI 助手一样。联网检索时不会上传你的病历文件。
- 导出分享时，只导出你选的文件，不含原件；会写明接收人、用途和到期日。**分享出去的副本收不回来**，也没有办法保证"完全匿名"。

## 声明

抗癌搭子是信息整理和导航工具，**不是医疗器械，不提供诊断或治疗建议**，不能替代医生。治疗相关的决定请和你的主诊团队一起做。如果出现呼吸困难、胸痛、意识改变、大出血等紧急情况，请立即去最近的急诊。
