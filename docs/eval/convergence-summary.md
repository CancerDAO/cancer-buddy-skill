## 迭代解决的核心问题（8 主题 + 收尾）

1. **价值前置，破 intake 墙**：多个子技能上来先抛整张问卷才给价值 → 先给当下能用的，再问 1–2 个最要紧澄清，"能答多少算多少"。（router 共享原则 + visit-prep/find-care/nutrition/case-precedent）
2. **内部语言不入患者视图（RL5）**：评级字母/QA术语/template_sha/PT编号一律不给患者看，缺口翻成"差哪几样材料"的人话。
3. **身份硬闸安全但不 dead-end**：识别人口学不符时先钉归属、不把吓人结论安到患者头上、核对期给去归属的一般解读 + 当场给低风险问医生清单，只 gate 建持久档案。
4. **声明溯源（RL1）**：清除无出处统计（"某调查显示 X%"），改经验性表述或明确"问医生"；disclosure 加显式 RL1 守则。
5. **可控可删 / 导出即用 / 仅本人可调取**：vault 三招 Trust-by-inspection；router 收尾常驻可控可删 + 隐私归属讲透。
6. **续接锚**：mind/caregiver "我一直在，随时回来"。
7. **披露中立**：告知/限时保护/分层同等被支持，决定权留给家庭。
8. **长度收敛 + 情绪校准**：濒临崩溃时收菜单、危机轮当场亮一个安全网号、check-in 锚到治疗节点给具体首次时间。
