# 癌种教育模块合同

癌种模块是按回答时核验来源生成的条件式教育，不是静态治疗路径。

## 必需输入

- 癌种与组织学的正式来源；
- 分期系统、分期和治疗意图的正式来源；
- 与问题直接相关的标志物、既往治疗和当前场景；
- 法域和查询日期。

缺失或冲突时展示 `unknown/disputed`，不得让模型或患者选择补成正式值。

## 模块结构

1. 这个癌种/亚型的稳定概念；
2. 医疗团队通常会核对哪些类别的信息，以及为什么；
3. “如果 A / 如果 B”条件图，但每一分支必须有当前适用指南的原子化引用；
4. 该指南人群与患者资料的关键差异；
5. 带给主诊医生的问题。

## 红线

- 不按当前 `profile` 自动输出个体治疗方向、换线、剂量或检查建议。
- 不将生物学机制写成具体药物适应证。
- 不跨癌种迁移随访、RECIST、标志物或分子检测规则。
- 不把“资料里没有”写成“需要补做”。只能询问是否已有相关报告可归档。
- 网络或原始指南不可用时，不用模型记忆生成方案名称或线次。

统一遵循 `guideline-lookup.md` 与根目录 `clinical-content-governance.md`。
