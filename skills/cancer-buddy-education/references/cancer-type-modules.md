# 癌种模块（患者版）

Per-cancer-type patient modules. Pull the section matching the patient's
`profile.json` → `diagnosis.primary_site` (or the closest match) into the
handbook. Content follows NCCN patient-guideline equivalent principles:
disease overview → common regimens → top-5 FAQ → daily-life tips → follow-up
cadence → red flags. Each module is 500–800 字, readable in 5–8 分钟.

All modules end with the same standardized footer:
`本内容为信息参考，具体方案与调整必须与主诊医生确认。`

## 肺癌 (Lung Cancer)

### 疾病简介

肺癌分为两大类：**非小细胞肺癌 (NSCLC)** 占 80–85%，含腺癌、鳞癌、大细胞癌；
**小细胞肺癌 (SCLC)** 占 15–20%，恶性程度更高、增殖更快。腺癌在我国不吸烟人
群中发病率上升明显，很多患者是体检发现。分期靠 TNM：I–II 期偏向手术，III 期
多模式联合（放化疗 ± 免疫巩固），IV 期以全身系统治疗为主。

### 常见治疗方案概述

- **早期 (I–II 期 NSCLC)**：首选手术切除，术后辅助化疗或靶向/免疫（如有驱动
  基因或 PD-L1 阳性）。
- **局部晚期 (III 期 NSCLC)**：同步放化疗 + 度伐利尤单抗巩固。
- **晚期 (IV 期 NSCLC)**：先做分子检测（EGFR/ALK/ROS1/KRAS/MET/RET/HER2/
  BRAF 等），有驱动基因用对应靶向药（奥希替尼、阿来替尼等）；无驱动基因看
  PD-L1 表达，PD-L1 高表达用免疫单药，否则化疗 + 免疫联合。
- **SCLC**：局限期用同步放化疗 ± 度伐利尤；广泛期用依托泊苷 + 铂类 + 阿替利
  珠/度伐利尤。

### 患者最常问的 5 个问题

1. **"医生说我是腺癌，是不是比鳞癌好一点？"** — 腺癌靶向药选择更多（EGFR、
   ALK 突变更常见），治疗选择空间大；鳞癌免疫治疗获益显著。不同病理类型不
   是简单的"好坏"，而是"治疗路径不同"。
2. **"我没吸过烟怎么还得肺癌？"** — 约 15–20% 肺腺癌发生在从不吸烟人群，与
   EGFR/ALK 等基因突变、厨房油烟、环境污染、家族史有关，不是你做错了什么。
3. **"为什么要做基因检测？贵不贵？"** — 基因检测决定用不用靶向药，差别巨大。
   有 EGFR 突变用奥希替尼，中位生存期可达 3 年以上；不测就可能错过最佳方案。
   NGS 多基因检测一般 8000–15000 元，部分地区已纳入医保或商保。
4. **"靶向药吃多久会耐药？"** — 一线 EGFR TKI 中位耐药时间约 18–24 个月。
   耐药后要重新活检 + 基因检测，找二次突变（如 T790M、C797S），通常还有下一
   线药物可用。
5. **"免疫治疗要打到什么时候？"** — 通常 2 年。若 2 年期满、病情稳定可停药
   观察。部分患者停药后长期无进展。

### 日常生活调整建议

- **戒烟 + 避免二手烟**：不管什么时候戒都有用；
- **家中使用抽油烟机 + 开窗通风**；
- **雾霾天戴 N95**；
- **接种流感疫苗、肺炎疫苗**（免疫治疗期间减毒活疫苗慎用，咨询医生）；
- **轻度有氧运动** (散步、太极) 对肺功能恢复有益。

### 随访节奏

- 术后前 2 年：每 3 个月 CT + 肿瘤标志物；
- 第 3–5 年：每 6 个月；
- 5 年后：每年一次。
- 晚期治疗中：每 6–8 周 CT 评效，必要时 PET/CT。

### 红旗警示

持续咳血、突发呼吸困难、剧烈胸痛、单侧肢体无力（警惕脑转移）、不明原因骨痛
（警惕骨转移）、免疫治疗期间持续腹泻 > 3 天或发热 > 38.5°C → **立即就医**。

## 乳腺癌 (Breast Cancer)

### 疾病简介

乳腺癌是我国女性最高发的癌种。按分子分型分四类：**Luminal A** (HR+/HER2-低
Ki67)、**Luminal B** (HR+/HER2-高 Ki67 或 HR+/HER2+)、**HER2 阳性**、**三阴
性 (TNBC)**。分型决定治疗路径的巨大差异。早期乳腺癌五年生存率 > 90%，是预后
最好的实体瘤之一。

### 常见治疗方案概述

- **保乳 vs 全切**：肿瘤 < 3cm 且位置合适通常可保乳 + 术后放疗，生存率与全
  切相同；
- **术后辅助**：HR+ 用内分泌治疗 5–10 年（他莫昔芬 / 阿那曲唑 / 来曲唑 ±
  CDK4/6 抑制剂）；HER2+ 用曲妥珠单抗 (± 帕妥珠单抗) 一年；TNBC 化疗为主，
  高危加免疫；
- **晚期**：根据分型选方案，HER2+ 有 DS-8201 等新一代 ADC；HR+ 晚期 CDK4/6
  抑制剂 + 内分泌一线；TNBC 用戈沙妥组单抗 (Trop-2 ADC)、PARP 抑制剂
  (BRCA 突变) 等。

### 患者最常问的 5 个问题

1. **"我是 HER2 阳性，是不是更严重？"** — HER2+ 过去确实凶险，但有了曲妥珠
   单抗、帕妥珠单抗、DS-8201 等靶向药后，预后反而比很多 HR+ 晚期还好。
2. **"内分泌治疗要吃 5 年还是 10 年？"** — 根据初始风险 (肿瘤大小、淋巴结、
   Ki67、Oncotype DX 等) 决定。高危患者延长到 10 年可降低复发，但要权衡骨质
   疏松、子宫内膜增厚等副作用。
3. **"乳腺癌会遗传吗？"** — 5–10% 的乳腺癌有遗传倾向，以 BRCA1/2 最常见。
   有家族史、50 岁前发病、双侧 / 三阴性建议做基因检测。阳性者一级亲属 (姐妹
   女儿) 也应筛查。
4. **"保乳后外观会很差吗？"** — 现代肿瘤整形技术可以做保乳 + 腺体整形、或
   保乳 + 即刻重建，大部分患者外观可接受。具体要看肿瘤位置和乳房大小。
5. **"术后能怀孕吗？"** — HR+ 患者内分泌治疗期间不能怀孕；近期研究（POSITIVE
   试验）显示治疗 2 年后暂停怀孕、生产后再继续治疗，短期不增加复发。必须与
   主诊医生和生殖科共同决策。

### 日常生活调整建议

- **术侧肢体保护**：避免提重物、测血压、抽血，预防淋巴水肿；
- **规律有氧运动 + 抗阻训练**：降低复发风险 20–30%；
- **控制体重**：BMI 正常范围，内分泌治疗期间体重容易上升；
- **饮食**：地中海饮食模式，限酒（每周 < 3 杯）；
- **避免保健品乱补**：高剂量植物雌激素可能干扰内分泌治疗。

### 随访节奏

- 术后前 2 年：每 3–6 个月门诊 + 肿瘤标志物；
- 每年一次乳腺超声 / 钼靶 / MRI；
- 内分泌治疗患者：每年骨密度、妇科超声 (他莫昔芬使用者)；
- 5 年后可拉长到每年一次。

### 红旗警示

术侧或对侧乳房新发肿块、皮肤橘皮样改变、腋窝淋巴结肿大、持续骨痛（警惕骨转
移）、持续胸闷气促（警惕肺转移）、头痛呕吐（警惕脑转移）→ **立即就医**。

*本内容为信息参考，具体方案与调整必须与主诊医生确认。*

## 结直肠癌 (Colorectal Cancer)

### 疾病简介

结直肠癌包括结肠癌和直肠癌，是我国发病率上升最快的癌种之一。分期仍用 TNM：
I–III 期靠手术 ± 术后辅助化疗可治愈，IV 期以全身治疗为主但部分肝肺寡转移可手
术根治。微卫星状态 (MSI-H / MSS) 决定免疫治疗适用性；RAS、BRAF、HER2 状态
决定靶向药选择。

### 常见治疗方案概述

- **I 期**：单纯手术，多数不需化疗；
- **II 期高危 / III 期**：术后辅助化疗 (FOLFOX 或 CAPEOX) 3–6 个月；
- **直肠癌**：T3–T4 或 N+ 先做术前放化疗 ± 免疫，再手术；
- **IV 期 MSS**：化疗 (FOLFOX / FOLFIRI) + 靶向 (左半 + RAS/BRAF 野生用西妥
  昔；右半或 RAS 突变用贝伐珠)；
- **IV 期 MSI-H**：免疫治疗一线 (帕博利珠单抗)；
- **BRAF V600E 突变**：康奈非尼 + 西妥昔单抗；
- **HER2 扩增**：曲妥珠 + 图卡替尼 或 DS-8201。

### 患者最常问的 5 个问题

1. **"要做肠造瘘吗？是永久的吗？"** — 低位直肠癌或紧急手术可能做临时造瘘，
   术后 3–6 月吻合口愈合后可还纳；极低位或肛门保不住才做永久造瘘。现代吻合
   技术让保肛率大幅提高。
2. **"做完手术还要化疗 6 个月太久了，能不能只做 3 个月？"** — IDEA 研究显示
   III 期低危患者 3 个月 CAPEOX 与 6 个月疗效相当，但高危仍推荐 6 个月。具体
   听你的肿瘤内科医生。
3. **"贝伐珠单抗会出血吗？还能手术吗？"** — 是的，所以使用贝伐后做手术需停药
   至少 4–6 周；鼻出血、尿血、便血都要报告。
4. **"MSI-H 是什么意思？"** — 微卫星高度不稳定，说明肿瘤 DNA 错配修复缺陷，
   基因组"很乱"，产生很多"异常抗原"，免疫系统容易识别 → 免疫治疗效果特别好。
   大约 15% 结直肠癌是 MSI-H。
5. **"肝转移还有救吗？"** — 肝寡转移 (≤ 3–5 处、局限) 经转化治疗后可手术，
   5 年生存率可达 30–50%，不是绝望局面。多学科讨论很关键。

### 日常生活调整建议

- **高纤维、少红肉、少加工肉**；
- **规律运动**：降低复发率和死亡率；
- **戒烟限酒**；
- **造瘘患者**：学习造口护理，参加造口协会互助；
- **化疗期间**：奥沙利铂末梢麻木要避免接触冷水冷风，戴手套；伊立替康前后注
  意腹泻，备洛哌丁胺。

### 随访节奏

- 术后前 2 年：每 3 个月门诊 + CEA，每 6 个月 CT；
- 第 3–5 年：每 6 个月门诊 + CEA，每年 CT；
- 术后 1 年查肠镜，之后 3 年一次、稳定后 5 年一次。

### 红旗警示

持续腹痛 / 腹胀、便血加重、排便习惯剧变、不明原因消瘦、黄疸（警惕肝转移）、
持续咳嗽（警惕肺转移）、造瘘口周围皮肤破溃或造瘘突然不排气排便 → **立即就医**。

## 肝癌 (Liver Cancer / HCC)

### 疾病简介

原发性肝癌 85–90% 是肝细胞癌 (HCC)。我国肝癌主要病因是乙肝 (HBV)，其次是丙
肝、酒精、脂肪肝。分期常用 BCLC（0 / A / B / C / D 期），同时要评估肝功能
（Child-Pugh）和体能状态。治疗选择高度依赖这三个维度的组合。

### 常见治疗方案概述

- **BCLC 0 / A (早期)**：手术切除 / 消融 (RFA / 微波) / 肝移植；
- **BCLC B (中期)**：TACE (经肝动脉化疗栓塞) ± 系统治疗；
- **BCLC C (晚期)**：系统治疗一线：阿替利珠 + 贝伐珠 (T+A) 或 STRIDE 方案
  (度伐利尤 + 替西利尤) 或仑伐替尼 / 索拉非尼 (不适合免疫者)；二线瑞戈非尼、
  卡博替尼、雷莫芦单抗 (AFP 高) 等；
- **HBV 阳性者全程抗病毒**（恩替卡韦 / 替诺福韦），是改善预后的基础。

### 患者最常问的 5 个问题

1. **"我的肝功能还能手术吗？"** — Child-Pugh A 级通常可以手术；B 级看具体指
   标和 ICG R15；C 级多数只能支持治疗或肝移植。
2. **"消融和手术哪个好？"** — ≤ 3cm 单发肝癌，消融与手术疗效相当，但消融
   创伤小、恢复快。大肿瘤或靠近血管仍建议手术。
3. **"我有乙肝，是不是一辈子都要吃抗病毒药？"** — 肝癌患者建议终身抗病毒，
   停药易反弹且增加复发风险。
4. **"TACE 后为什么发烧腹痛？"** — 栓塞后综合征（发热、腹痛、恶心），因为
   栓塞后肿瘤缺血坏死引起，通常 3–7 天缓解。超过 1 周或高热不退要排除感染。
5. **"免疫 + 抗血管方案会不会出血？"** — 贝伐珠单抗有出血风险，治疗前要做
   胃镜排除食管静脉曲张。曲张 F2 以上先套扎再用。

### 日常生活调整建议

- **绝对戒酒**；
- **乙肝家族定期筛查 (半年一次 B 超 + AFP)**；
- **规律作息，避免过度劳累**；
- **慎用保健品和中药**：很多肝损伤来自不明成分补品；
- **饮食**：适量蛋白 (1.0–1.2 g/kg/日)，避免霉变食物。

### 随访节奏

- 术后 / 消融后前 2 年：每 3 个月 AFP + 肝脏影像 (增强 CT / MRI)；
- 第 3 年后：每 6 个月；
- 系统治疗期间：每 6–8 周评效；
- 终身监测 HBV DNA + 肝功能。

### 红旗警示

呕血 / 黑便 (警惕食管静脉曲张出血)、意识改变 / 行为怪异 (警惕肝性脑病)、腹水
突然增多、黄疸加深、持续右上腹剧痛 → **立即就医**。

*本内容为信息参考，具体方案与调整必须与主诊医生确认。*

## 胃癌 (Gastric Cancer)

### 疾病简介

胃癌在我国发病率位居前列，幽门螺杆菌（Hp）感染是首要诱因。按解剖分胃食管结
合部癌 (AEG) 和胃体 / 胃窦癌；按病理分肠型和弥漫型 (Lauren 分型)；按分子分
MSI-H / EBV 阳性 / HER2 阳性 / CLDN18.2 阳性 等亚型，越来越精准。

### 常见治疗方案概述

- **早期 (Tis–T1a)**：内镜黏膜下剥离术 (ESD)；
- **可切除 (II–III 期)**：围手术期化疗 (FLOT 方案) + 根治手术；
- **晚期 HER2 阳性**：化疗 + 曲妥珠单抗 + 帕博利珠单抗 (KEYNOTE-811)；
- **晚期 HER2 阴性 PD-L1 CPS ≥ 5**：化疗 + 纳武利尤 / 帕博利珠；
- **晚期 MSI-H**：免疫单药或联合；
- **晚期 CLDN18.2 阳性**：佐妥昔单抗 + 化疗（新可选）；
- **Hp 根除**：早期胃癌术后及有 Hp 家族成员均推荐根除。

### 患者最常问的 5 个问题

1. **"胃切除后怎么吃东西？"** — 少食多餐 (6–8 次 / 日)、细嚼慢咽、慎食甜食
   (防倾倒综合征)、终身补充维生素 B12 (全胃切除) 和铁剂。营养师随诊很关键。
2. **"胃切除后会瘦多少？"** — 术后半年内可能减 5–15 公斤，之后趋于稳定。
   体重持续下降要警惕营养不良或复发，应及时就医。
3. **"HER2 阳性为什么还要打免疫？"** — KEYNOTE-811 显示 HER2+ 胃癌加免疫显著
   提高缓解率和生存期，已成新标准。
4. **"化疗后手脚麻木怎么办？"** — 奥沙利铂神经毒性常见，要早报告。严重时需
   减量或换伊立替康等方案，不能硬扛导致永久损伤。
5. **"Hp 全家都要查吗？"** — 一级亲属 Hp 感染率和胃癌风险都高，建议一起做
   13C 呼气试验并根除。
### 日常生活调整建议

- **低盐 + 少腌制食品 + 多新鲜蔬菜水果**；
- **根除 Hp 并复查**；
- **戒烟限酒**；
- **胃大部切除后分餐 + 饭后半卧位 30 分钟防反流**；
- **补钙、维 D、B12**；
- **定期监测血红蛋白 + 铁蛋白**。

### 随访节奏

- 术后前 2 年：每 3–6 个月胃镜 + CT + CEA + CA19-9 + CA72-4；
- 第 3–5 年：每 6–12 个月；
- 终身 B12 / 铁 / 营养评估。

### 红旗警示

呕血 / 黑便、进行性吞咽困难、剧烈上腹痛、黄疸（警惕肝转移）、快速消瘦或大量
腹水、贫血（警惕慢性出血）→ **立即就医**。

*本内容为信息参考，具体方案与调整必须与主诊医生确认。*

## 淋巴瘤 (Lymphoma)

### 疾病简介

淋巴瘤是血液淋巴系统肿瘤，分为**霍奇金淋巴瘤 (HL)** 和**非霍奇金淋巴瘤 (NHL)**
两大类。NHL 种类繁多（DLBCL、FL、MCL、PTCL 等 60+ 亚型），治疗方案差别很大。
总体来说淋巴瘤化疗 + 免疫治疗敏感，很多亚型可治愈，不要被"癌"字吓倒。

### 常见治疗方案概述

- **经典霍奇金淋巴瘤 (HL)**：ABVD 或 BEACOPP (高危)；早期局限 + 巩固放疗；
  复发 / 难治可用 PD-1 (纳武利尤、替雷利珠)、BV (本妥昔单抗维多汀)、ASCT。
- **DLBCL (弥漫大 B)**：R-CHOP × 6–8 周期，高危可 Pola-R-CHP；复发用 CAR-T
  (阿基仑赛、瑞基奥仑赛) 或 R-ICE + ASCT。
- **滤泡淋巴瘤 (FL)**：低肿瘤负荷可观察等待；有症状用 R-CHOP / BR / 来那度胺
  + 利妥昔。
- **套细胞 (MCL)**：R-CHOP / VR-CAP / BTK 抑制剂 (伊布替尼、泽布替尼)。
- **T 细胞 (PTCL / ALCL)**：CHOP / CHOEP；ALK+ ALCL 预后好，ALK- 预后差。

### 患者最常问的 5 个问题

1. **"淋巴瘤能治好吗？"** — 霍奇金早期 5 年无病生存 > 90%；DLBCL 一线治愈率
   60–70%；滤泡虽不易根治但中位生存 > 15 年。很多亚型是"可治愈的癌症"。
2. **"为什么要用这么多种药（R-CHOP 里 5 种）？"** — 淋巴瘤异质性强，单药容易
   耐药。经典方案是经过几十年临床验证最佳组合。
3. **"利妥昔单抗输液过敏怎么办？"** — 首次输注过敏常见，预防性用抗组胺 + 糖
   皮质激素、慢速输注。严重反应要停药并更换抗 CD20（如奥妥珠单抗）。
4. **"骨髓抑制会持续多久？"** — 化疗后第 7–14 天最低，一般 7–10 天回升。
   粒细胞 < 0.5 或发热要立即就医（粒缺发热）。
5. **"CAR-T 听起来很贵也很吓人，值不值得？"** — 复发难治 B 细胞淋巴瘤 CAR-T
   完全缓解率可达 40–50%，部分患者长期无病。价格目前 100–120 万，部分商保可
   覆盖，少数城市纳入惠民保。

### 日常生活调整建议

- **化疗期间避开人群、戴口罩**（粒缺期感染高风险）；
- **口腔护理 (软毛牙刷 + 漱口液)** 预防口炎；
- **多喝水**，帮助排出肿瘤溶解物；
- **心肺监测**：蒽环类药物累积剂量要控制，做心脏超声；
- **疫苗**：治疗结束后 6 月可重新评估疫苗接种。

### 随访节奏

- 诱导化疗中：每 2 个周期评效 (PET/CT)；
- 治疗结束后前 2 年：每 3 个月门诊 + LDH + 浅表淋巴结超声；
- 第 3–5 年：每 6 个月；
- 5 年后：每年一次，终身监测第二原发肿瘤。

### 红旗警示

化疗期间发热 > 38.5°C（粒缺发热是急症）、呼吸困难、持续心悸胸痛、新发浅表
或深部淋巴结肿大（复发）、持续盗汗 + 消瘦（B 症状复发）→ **立即就医**。

## 未列出癌种怎么办？

如果患者癌种不在上述 6 种之内（如食管癌、胰腺癌、妇科肿瘤、头颈癌、泌尿肿
瘤、血液肿瘤其他亚型等），按如下替代策略：

1. 从 MTB 报告直接抽取该癌种的"诊断 + 分期 + 当前方案"放入"疾病简介"段；
2. FAQ 用通用 5 问替代："我的分期预后如何？治疗几线了？下一步备选方案？生活
   中需要注意什么？复诊节奏？"
3. 随访节奏按 NCCN / CSCO 对应癌种指南 (术后 2 年内每 3–6 月、3–5 年每 6–12
   月、5 年后每年)；
4. 红旗警示：固定三项 "高热不退 / 新发剧痛 / 不明出血"，+ 癌种相关三项 (脑转
   移 → 头痛呕吐；肝转移 → 黄疸；肺转移 → 呼吸困难；骨转移 → 病理性骨折)。

遇到罕见癌种、儿童癌种、孕期合并癌种，务必转诊至有亚专科经验的中心。
