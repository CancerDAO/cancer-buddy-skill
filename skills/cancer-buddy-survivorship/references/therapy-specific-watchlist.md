# 治疗特异性晚发效应 watchlist

## 蒽环类 (阿霉素 / 表阿霉素 / 柔红霉素)

- **心脏毒性**：终身风险，剂量累计依赖
- 临床：左室射血分数降低 → 心衰
- 监测：治疗结束后每年 ECG + 超声心动 (LVEF)
- 累积剂量 > 450 mg/m² 阿霉素 → 更密切监测
- 儿童患者 → 终身监测
- 干预：发现心功能下降 → 心内科评估 + ACEi/ARB / β-blocker

## 胸部放疗 (Hodgkin / 乳腺 / 肺)

- **继发乳腺癌**（胸部放疗年轻女性）：从放疗 8 年后开始年度乳腺 MRI + 乳腺 X 线
- **继发甲状腺癌**：每年触诊 + 必要时超声
- **心血管疾病**：加速动脉粥样硬化，关注血脂和血压
- **肺纤维化**（长期）
- **瓣膜病**（长期）

## 铂类 (顺铂 / 卡铂 / 奥沙利铂)

- **肾功能**：长期 eGFR 下降
- **听力**：高频听力受损（尤其顺铂）→ 听力图每年
- **外周神经病变**：感觉异常、麻木（尤其奥沙利铂）→ 可能永久
- **电解质**：镁、钾长期低

## 烷化剂 (环磷酰胺 / 异环磷酰胺 / 美法仑)

- **继发急性白血病 / MDS**：治疗后 5-10 年风险显著升高
- **生育能力**：不孕常见（尤其大剂量）
- **膀胱毒性**（异环磷酰胺 → 出血性膀胱炎）
- **肺纤维化**（博来霉素 + 环磷酰胺）

## 紫杉类 (紫杉醇 / 多西他赛)

- **外周神经病变**：手足麻木、刺痛、灼烧感 → 可能持续数月数年
- **关节痛 / 肌痛**：偶见长期
- **指甲改变**

## 免疫治疗 (PD-1 / PD-L1 / CTLA-4)

- **内分泌紊乱可长期**：甲减、肾上腺功能不全、1 型糖尿病
- **慢性皮疹 / 湿疹**：部分患者持续
- **罕见但严重**：心肌炎延迟表现、Guillain-Barré

## 靶向治疗 (TKI)

- **长期使用 TKI** 副作用大多可逆，但某些（如索拉非尼、瑞戈非尼的手足综合征）可积累
- **EGFR TKI 间质性肺病**：偶见长期肺改变
- **ALK 抑制剂**：部分患者视力改变、认知变化

## 激素治疗 (他莫昔芬 / 阿那曲唑 / 来曲唑)

- **骨密度下降**（芳香化酶抑制剂）→ 年度 DEXA + 钙 + 维生素 D
- **血栓风险**（他莫昔芬）
- **子宫内膜改变**（他莫昔芬）→ 年度妇科
- **关节痛**（芳香化酶抑制剂，约 50% 患者）

## 骨髓移植 / CAR-T

- **移植物抗宿主病**（BMT）：慢性皮肤/肝/肠/肺表现
- **继发肿瘤**
- **免疫缺陷**终身
- **CAR-T 细胞因子风暴长期影响**：数据仍在积累

## 儿童肿瘤治疗（成年后监测）

- **生长激素缺乏**（颅脑放疗）
- **不孕 / 性腺功能不全**
- **认知影响**（放疗 + 大剂量甲氨蝶呤）
- **继发肿瘤**风险显著高于普通人群
- 此类患者 → 终身 "儿童肿瘤成年后随访"（多数中国中心尚未完善，参考 COG-LTFU 指南）

## 血液肿瘤（化疗 / 移植后）

- **继发 MDS / AML**：尤其 烷化剂 + 依托泊苷方案
- **骨髓储备下降**
- **感染易感性**
