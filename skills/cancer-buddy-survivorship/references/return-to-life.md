# 回归生活指南

治疗结束不等于"回到从前"。你的身体经历了战争，现在要重建。

## 回到工作

- **全职 vs 渐进**：很多生存者希望立刻全职回到 pre-cancer 状态——这通常不现实，fatigue 可能持续数月
- **法律权益（中国）**：病假期间用人单位不得随意解除劳动合同（《劳动法》）；返岗可协商减负或调岗
- **披露给同事**：你的选择，没有对错。很多人选择只告诉直属上司和关键同事
- **renewed sense of purpose** 常见——有些生存者转行做癌友支持、写作、慢生活

## 锻炼

- 治疗期 + 治疗后**规律运动降低复发风险**（乳腺癌、结直肠癌、前列腺癌证据最强）
- 建议：每周 150 分钟中等强度有氧 + 2 次阻力训练
- 入门：步行 → 游泳 → 瑜伽 → 抗阻
- 化疗引起的外周神经病变：从低冲击开始（骑车、游泳）
- 肌肉减少症（老年生存者）→ 阻力训练尤其重要

## 饮食

- 地中海 / 植物为主：多蔬菜水果、全谷物、豆类、鱼、橄榄油
- 减红肉（尤其加工肉）
- 糖 / 深加工食品：限量
- 酒精：乳腺 / 肝 / 头颈癌生存者应戒；其他限量（每日 ≤ 1 份）
- 体重：超重 BMI > 25 与多种癌复发风险相关——逐步减重

## 戒烟

- 肺癌、头颈癌、膀胱癌生存者：**戒烟显著降低二原发风险**
- 戒断工具：尼古丁替代、伐尼克兰、安非他酮
- 反复失败是常见——不是道德问题，是生理依赖；坚持重试

## 性与亲密

- 化疗 / 放疗常带来：阴道干涩、勃起困难、性欲下降、疲劳影响 libido
- **不是 taboo**——和配偶一起和医生谈
- 妇科生存者：阴道保湿剂、扩张器；必要时雌激素局部治疗（激素依赖癌种需谨慎）
- 男性：勃起功能障碍治疗（PDE-5 抑制剂、真空装置、植入）
- **心理因素**：伤疤、身体形象改变、fatigue — 伴侣关系再沟通

## 生育

- 青年生存者（< 40 岁）：治疗可能永久影响生育
- 如果之前未做生育保存，现在的选择：自然受孕（随时间逐渐恢复）、收养、第三方辅助生殖
- 乳腺癌：怀孕对大多数类型不增加复发风险；他莫昔芬用药期避免怀孕
- 遗传咨询：BRCA / Lynch / Li-Fraumeni 等遗传综合征 → 胚胎筛查

## 关系修复

- 照护者 burnout → 你治好了，Ta 也需要时间
- 家庭角色洗牌：你不再是"病人"，也不是完全的"pre-cancer 你"
- 朋友会变：有些人坚定陪伴，有些人淡出——正常
- 新朋友：癌友社群往往提供独特的理解

## 财务恢复

- 治疗期积累的医疗债务：分期、协商减免
- 生育保险 / 长期残疾保险重新评估
- 职业转型如果旧工作不再可行

## 复发恐惧 (FCR: Fear of Cancer Recurrence)

- 每次扫描前焦虑（scanxiety）→ 见 [scanxiety.md](scanxiety.md)
- 日常小头痛 / 小肿块引发恐慌
- 强度不同：轻度 "偶尔想想" vs 重度"影响日常功能"
- 重度 FCR → 路由到 `cancer-buddy-mind`

## 意义感重建

- 很多生存者报告："癌症让我重新想什么重要"
- 志愿/咨询/写作/教导年轻癌友——不是每个人都想做，也不是每个人都不想做
- 不急。给自己 1-2 年。
