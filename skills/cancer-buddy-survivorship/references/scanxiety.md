# Scanxiety — 扫描前后焦虑

每次复查扫描前的焦虑是生存者标志性情绪之一，几乎普适。

## 为什么

- 癌症从"看不见的细胞"到"可见的病灶"需要几个月——扫描是唯一的可见窗口
- 每次扫描都可能改变你的生活
- "等结果"的几小时到几天 = 失控感

## 常见模式

- 扫描前 1-2 周开始失眠、易怒、反复检查身体
- 扫描当天到拿结果的窗口：高度焦虑
- 结果阴性 → 短暂如释重负 → 2-3 个月后又开始下轮焦虑

## 应对策略

### 扫描前

- 提前安排好扫描后的事情——**结果当天不工作 / 不开会**
- 身边有信任的人（配偶 / 成年孩子 / 朋友）—— 不要独自拿结果
- 限制自己"自查身体" 的次数 — 越查越焦虑
- 提前和医生约好结果反馈时间 — 不要拿到报告自己看

### 扫描当天

- 带陪伴
- 带耳机听音乐（MRI 尤其）
- 镇静剂：如果严重焦虑 → 可术前开 0.5 mg 劳拉西泮
- 深呼吸 / 感觉扎根（ground）技巧

### 等结果的窗口

- **短**：如果医院系统允许，问医生"结果出当天可否电话告知"
- **分心**：做需要注意力的事（运动、陪家人、做菜），不做需要深思考的决定
- **不求证朋友**："我觉得我有点咳嗽你觉得严重吗" → 这些对话消耗能量但解决不了

### 结果后

- **稳定 / 持续缓解**：庆祝 + 3-6 个月后下一轮——不要期待"完全放心"
- **变化 / 进展**：触发 `cancer-buddy-inflection`
- **不确定 / 重复扫描**：最煎熬，给自己 + 2 周
- **假阳性复发 confusion**：先确认第二意见再做决定

## 什么时候是病理性的

- 扫描前 2 周焦虑严重影响睡眠 / 工作 / 家庭
- 扫描间期 ( > 2 个月前后) 依然高度焦虑
- 身体症状（心悸、惊恐、回避就医）
- **路由到 `cancer-buddy-mind`**：PHQ-9 / GAD-7；可能需要短期抗焦虑药 + CBT 专项治疗 FCR

## 认知技巧

- **概率 vs 恐惧不匹配**：你的复发概率可能是 10% / 年；恐惧感受像 90%——正常但需要 reframe
- **"复发 ≠ 死亡"**：许多复发可治，再治再缓解
- **"不焦虑 ≠ 不在乎"**：允许自己暂时不想这件事，不是背叛谨慎

## 家属支持

- 不要说"别担心，你已经治好了"—— 无效，且让 Ta 感到不被理解
- 说"扫描前后你可能会很累，我那几天少安排，给你留空间" —— 有效
- 和 Ta 一起制定扫描后一天的"自我关怀日"
