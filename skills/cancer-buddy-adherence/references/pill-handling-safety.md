# 片剂处理安全

## 不可掰分 / 压碎 / 打开的药

### 缓释 / 控释片

- **不可掰分、压碎、嚼碎**
- 破坏释放机制可能导致瞬时高剂量 → 严重毒性
- 示例：瑞戈非尼、曲美替尼、依维莫司（不掰）

### 细胞毒性药物

- 化疗口服药（卡培他滨、替莫唑胺、环磷酰胺）**不可徒手压碎或打开胶囊**
- 原因：粉末接触皮肤或呼吸道有职业暴露风险
- 若患者无法吞服完整片/胶囊 → 联系医生换剂型或喂养方式

### 靶向药一般不建议掰分

- TKI 类药物通常不建议掰分，即使说明书没禁，因生物利用度可能改变
- 如必须（比如半片剂量试验）→ 问药师

## 储存

| 药物类 | 储存 |
|---|---|
| 多数口服化疗 / 靶向 | 室温 (15-25°C)，避光，干燥 |
| 华法林 | 室温 |
| 液体 / 混悬 | 可能需冷藏（看标签）|
| 类固醇 | 室温 |

- 浴室**不是**好的存药处（潮湿）
- 厨房**不是**好的存药处（温度波动）
- 卧室抽屉 + 小除湿袋是合适的家庭选择
- 冰箱存药只在说明书要求时

## 过期处理

- 不要冲进马桶（环境污染）
- 部分医院 / 药房有 take-back 服务
- 实在没有：密封容器 + 咖啡渣混合 + 普通垃圾

## 家中有小孩或宠物

- 必须儿童安全瓶
- 高处 + 上锁
- 误食 → 立即致电 120 + 带药瓶去急诊

## 护理家属接触注意

- 细胞毒性药物：处理后洗手；接触呕吐物 / 排泄物戴一次性手套 48 小时内
- 正常口服靶向药：普通手卫生足够
- 多数药物**不会**通过正常皮肤接触造成照护者暴露——不要过度恐慌

## 旅行

- 不托运（温度 / 遗失风险）
- 原包装 + 医生处方复印件
- 跨时区：短期（< 3 小时时差）按当地时间即可；长期跨时区 → 逐步移动 2-3 小时 / 日

## 忘带药出门

- 一日药：回家尽快；遵守 missed-dose-rules.md
- 多日出行忘带：联系当地医院或药房，带处方本可补开（有些 TKI 紧俏难补）
