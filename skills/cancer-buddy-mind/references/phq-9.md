# PHQ-9 — 患者健康问卷-9 (depression screener)

> **Administration.** Ask permission first and use an official validated PHQ-9 form in the user's language. The Chinese text below is a reference rendering, not permission to claim that an LLM-generated translation is validated. Keep item order and 0–3 scoring only when using a validated form. Cancer and treatment can contribute to sleep, appetite, energy, and concentration symptoms; interpret the result as a screen, never a diagnosis.

过去两周里，您有多少时候受到以下问题的困扰？

按 0-3 评分: 0=完全没有, 1=有几天, 2=一半以上的天数, 3=几乎每天

1. 做事时提不起劲或没有兴趣
2. 感到心情低落、沮丧或绝望
3. 入睡困难、睡不安稳或睡眠过多
4. 感觉疲倦或没有活力
5. 食欲不振或吃太多
6. 觉得自己很糟，或觉得自己是个失败者，或让自己或家人失望
7. 对事物专注有困难，例如阅读报纸或看电视时
8. 动作或说话速度缓慢到别人已经觉察？或正好相反——烦躁或坐立不安、动来动去的情况更胜于平常
9. **有不如死掉或用某种方式伤害自己的念头**

## 评分

总分 0-27:

| 总分 | 程度 | 建议 |
|---|---|---|
| 0-4 | 无/极轻 | 观察 |
| 5-9 | 轻度 | 自助 + 2 周后复测 |
| 10-14 | 中度 | 建议心理咨询 |
| 15-19 | 中重度 | 建议心理咨询 + 精神科评估 |
| 20-27 | 重度 | 尽快安排专业评估；总分本身不等于正在发生的自杀急症 |

## 题 9 安全跟进

- **题 9 ≥ 1**（任何频率的死亡/自伤想法）→ 立即暂停计分解释，按 `cancer-buddy-mind` 直接询问当前行动、意图、计划、手段可及性和是否独处。
- 是否需要急救取决于当前行动/意图/计划/手段，而不是总分。

需要结构化进一步评估且用户同意时，可使用与场景/语言匹配的官方 C-SSRS；量表不能覆盖现实中的高风险信号。

## 纵向追踪

可每 2–4 周复测。默认不保存；只有解释用途并取得明确同意后，才保存最小必要结果。
