# 病例文献检索来源

## 数据源角色

- PubMed/MEDLINE 与 Europe PMC 可能收录同一记录，不视为独立证据；按 DOI、PMID、题名、作者、机构、时间和患者特征去重。
- 使用期刊官网/出版商页面核对全文、补充材料、更正、关注表达和撤稿。
- 使用 Crossref/Retraction Watch（如许可）和期刊记录交叉核查状态。
- 使用 ClinicalTrials.gov、WHO ICTRP 或法域注册平台核对相关试验，但注册记录不是疗效证明。

## 检索策略

不要只用 publication type=`Case Reports`，因为索引可能缺失或滞后。组合癌种、组织学、精确变异/靶点、干预、case report/series、exceptional response、toxicity、death、progression 等术语，并记录完整式子。

检索必须覆盖不良结局和严重毒性，不能只围绕“成功”。同一病例的会议摘要、预印本、病例报告和后续系列应建立链接，防止重复计数。

网络或全文不可用时标 `unverified`；不根据摘要补写剂量、疗效或患者特征。
