# 病例文献输出模板

## 1. 检索审计

- 检索问题、数据库、检索式、日期、命中/去重/纳入数量；
- 纳入排除标准；撤稿、更正和重复患者核查。

## 2. 病例逐条事实表

每例只写论文明确报告的患者、干预、并行治疗、结局、不良事件和随访，并给 DOI/PMID/注册号/直接 URL。推断字段标 `not reported`，不补全。

## 3. 不可比因素

按 `similarity-axes.md` 展示相同、不同、未知和不可比较，不给总分或排序。

## 4. 偏倚与不确定性

按 `bias-disclosure.md` 展示不良/缺失结局、发表偏倚、选择偏倚、混杂、归因限制和重复发表风险。

## 5. 研究问题，不是治疗方向

允许输出：`这篇病例提出了一个可供主诊团队/研究团队核对的研究问题：……`

禁止输出：`治疗方向`、`值得尝试`、`最匹配`、`成功案例证明`、获益概率、患者适用性或具体获取路径。

页脚：

> 病例报告不能证明疗效或预测个人结果；不要据此开始、停止或更改治疗。
