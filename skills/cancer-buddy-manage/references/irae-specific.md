# 免疫相关不良事件 (irAE) 专题

PD-1/PD-L1/CTLA-4 抑制剂的副作用和化疗不同——是**免疫系统被激活攻击自身器官**，可能致命，需要早识别、早介入、**不能靠"扛一扛"**。

## 硬规则

**任何 irAE ≥ Grade 2 → 必须联系肿瘤科讨论是否暂停免疫治疗 + 启动糖皮质激素**。不是"下次复诊再说"。

**Grade 3-4 → 急诊 + 住院评估**。不要等。

## 常见 irAE 系统

### 肺炎 (Pneumonitis)

- 症状: 咳嗽、呼吸困难（尤其活动后）、胸痛、低氧
- 时间: 开始免疫治疗后 2-24 周，中位 ~3 个月
- **Grade 2+ (新出现呼吸困难、运动耐量下降) → 立即就诊 + CT + 评估激素**
- 致死率高——任何新发咳嗽或气促都要告诉医生

### 肠炎 / 腹泻 (Colitis)

- 症状: 腹泻、腹痛、血便、发烧
- 时间: 2-12 周
- **Grade 2 (> 4 次/天) → 联系医生，开始口服激素**
- **Grade 3 (> 7 次/天或血便) → 急诊，静脉激素；必要时英夫利昔**
- 不同于化疗腹泻——对洛哌丁胺反应差

### 肝炎 (Hepatitis)

- 症状: 无症状最多——全靠抽血发现
- 指标: ALT / AST / 胆红素升高
- **Grade 2 (AST/ALT 2.5-5× ULN) → 暂停免疫 + 密切复查**
- **Grade 3 (5-20× ULN) → 急诊激素**

### 内分泌紊乱

- **甲状腺**: 最常见。甲亢初期 (心悸、消瘦) → 甲减维持 (疲乏、体重增加、怕冷)
  - 多数需终身甲状腺激素替代
- **垂体炎**: 头痛、视力改变、疲乏、低血压、低血糖、多尿
  - 可能危及生命，需激素替代（有时终身）
- **1 型糖尿病**: 罕见但可暴发性发病 → DKA (酮症酸中毒) → 急诊
- **肾上腺危象**: 低血压、恶心、腹痛、电解质紊乱 → 急诊

### 皮肤

- 大多 Grade 1-2，润肤+外用激素
- **Grade 3-4 (广泛水疱、SJS/TEN、黏膜受累) → 急诊**

### 心肌炎

- **罕见但致命**——发生率低但死亡率高
- 症状: 胸痛、心悸、气促、水肿
- 任何新发心脏症状 → 急诊 + 心肌酶 + 心电图
- 不能等门诊排期

### 神经系统

- 周围神经病变、重症肌无力、Guillain-Barré
- 新发无力、复视、吞咽困难 → 急诊

### 肾炎

- 血肌酐升高（通常无症状）
- 常规抽血发现

## 患者自助卡片（可打印或截屏）

```
我正在用 免疫治疗 (药名: _____)

如果我出现以下任一症状，请立即联系我的肿瘤科医生或去急诊:
- 新发咳嗽或呼吸困难
- 腹泻 ≥ 4 次/天 或 血便
- 胸痛、心悸、下肢水肿
- 剧烈头痛、视力模糊、严重乏力
- 广泛皮疹 或 皮肤起泡、口腔溃烂
- 皮肤或眼白发黄

我的医生: _____ 电话: _____
急诊医院: _____
用药告知: "正在接受 PD-1 抑制剂治疗，可疑 irAE"
```

## 告诉患者什么

- 免疫治疗**不是无副作用**。它用你的免疫系统打肿瘤——免疫系统也可能误伤自己。
- 任何不对劲的症状都要说。不要"扛一扛"——irAE 扛不出来，只会延误。
- 带那张自助卡。急诊不是肿瘤专科，你要主动告诉他们你在用免疫治疗。
