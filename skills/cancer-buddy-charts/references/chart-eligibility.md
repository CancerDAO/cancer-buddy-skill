# 画图资格门

继承 `cancer-buddy-organize/references/cancer-trend-markers.md`，本文件是它在图表侧的执行细则。冲突时以 `cancer-trend-markers.md` 为准。

## 1. 序列资格（全部满足才可绘制）

1. 同一 analyte / 方法，单位可比，跨 ≥2 份源报告确认
2. 每个点有标本或报告日期 + `source_ref` 锚点
3. 无未决的 OCR / 单位 / 身份 / 来源冲突
4. 用户主动要求，或临床医生书面计划明确指定该指标随访（解释见 §2）
5. 说明文字纯描述，无疗效解释

不满足时**说明原因**，不静默略过。"目前只有一次记录"本身是有用信息——它告诉患者再测一次就能看到趋势。

## 2. 条件 4 的解释

原文 *"the user requests the graph"* 中 request 的对象是 **analyte，不是图形形式**。

患者问「我的 CEA 怎么样」即已 request 了该 analyte 的完整呈现。图是**回答的形式**，不是新增的临床判断。

补充理由：**文字答单点比画图更危险**。「你最新的 CEA 是 8.1」把一个孤立数值交给患者去焦虑；完整序列（含参考区间、方法变更、数据空档）反而更接近真相。在这个场景里图是**降低误读**的手段。

这也是它不得越出 §7 边界的原因——一旦系统开始替患者挑指标，上面这条理由就不成立了。

## 3. 参考区间

- 只用该次报告自带的 `reference_range`
- **禁止套用通用参考值**：不同实验室、不同方法的区间不同
- 解析不出（含性别分段、年龄分段、多区间）→ 不画区间带，并明确写"本次报告未提供可解析的参考区间"
- 缺失和"恰好在区间内"在视觉上必须可区分

## 4. 方法与单位

- `method_or_device` 变化 → 序列断开分段，不连成一条线
- 单位不一致 → 不做换算，标注并提示与主诊团队核对
- 只有在存在确定性、可验证、保留原值并记录公式的换算时才允许统一单位

## 5. 用色

- 参考区间内 → 主紫。**不用绿色**（绿色暗示"好"，是隐性判断）
- 超出参考区间 → 琥珀描边，不填充
- 红色 → **仅**用于源报告自身标注的危急值。红色转述的是源报告的标记，不是我们的判断
- 不画趋势方向箭头

理由见 `chart-style.md §红色克制`。

## 6. 说明文字与回答边界

标题写读图指引，不写结论也不复读数字。三层规则见 `SKILL.md §标题怎么写`。
判决词黑名单是**地板**，不是全部判定。

**回答指标问题分两轴，不要整块拒答**（与 `cancer-buddy/SKILL.md` 的闸门原则一致）：

- **放开**：指标是什么、一般反映什么、常见影响因素、为什么不同医院区间不同、不同方法为什么
  不可比、指南对这类指标的一般随访做法（实时核验一手来源后带源转述）、怎么读这张图
- **收紧**：对**本人这组数字**的判决——是否提示疗效变化/进展/复发、要不要换方案、要不要加做
  检查、预后如何

收紧部分用一两句自然写在回答里，不写"我不能替你做的"这类免责段落，也不要每张图重复一遍边界
声明。先把能答的答透，个案决定再落回医生。

## 7. 主动识别边界

约束的是**主动出图**（用户没开口要图时系统自己附上），不是用户明确要求时的数量。

- 主动附图只画**用户问到的** analyte，不主动扩展到他没问的指标
- 泛问（"我的化验单怎么样"）不自动出图；先列出哪些指标成序列，让用户挑
- 不满足绘图条件时说明原因，不静默略过

**用户明确要求时不设数量上限。** "把这些都画出来"、"全都要"是用户在选，不是系统在替他选
——§8 那条被撤回的做法坏在系统替患者挑指标，与用户主动点名要几张无关。逐张守 §1 资格门，
画不出来的逐个说明原因。

## 8. 历史约束：一条已被撤回的做法

`CHANGELOG.md:165` 记录，`cancer-trend-markers.md` 最初是一张 **"全 69 NCCN 癌种 → 疗效监测血清标志物"对照表**（27 癌种有公认标志物 / 42 显式标 `—` / 4 标"存疑"）。它后来被**整体撤回**，撤回理由写在现文件开篇：癌种本身不足以选定标志物，且许多标志物不是有效的独立疗效度量。

| | 已撤回的做法 | 路径 C |
|---|---|---|
| 谁选指标 | **系统**按癌种决定哪个标志物值得追踪 | **患者**问了哪个就是哪个 |
| 性质 | 隐性临床判断（把 marker 提升为 response monitor） | 把患者问的问题答完整 |

**§7 的每一条都是在守住这道分界。** 尤其"严禁主动扩展"——一旦开始"顺便也画个 CA19-9"，系统就重新变成了那张被撤回的表。实现与 review 时以此为准绳。
