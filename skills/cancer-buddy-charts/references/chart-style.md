# 图表设计规范

Token 的唯一权威是 `scripts/chart_core.py` 顶部的常量。本文件解释规则与理由；数值以代码为准。

## 色板

| 用途 | 值 |
|---|---|
| 主紫 / 强调 | `#6b4bb3` `#7c5cff` |
| 浅阶 ladder（浅→深） | `#f4ecff` `#ece4fb` `#e7d1ff` `#c9a4ff` `#a678ee` |
| 深底 / 正文 | `#2b2340` |
| 次要 / 三级文字 | `#8b7fa6` `#574a6e` |
| 参考区间带 | `#f4ecff` |
| 细线 / 家具 | `#ece4fb` |
| 区间外（描边） | `#b7791f`，底 `#fdf3e2` |
| 源报告危急值 | `#c0392b`，底 `#fdeeee` |
| 卡片底 | `#ffffff` `#fcfaff` |

`validate_chart_svg.py` 检查项 (d) 锁死这张表，出现表外颜色即失败。

**编码规则：色相 = 语义，明度 = 数值。** 参考区间内 / 外是分类语义，灰阶承载不了；明度通道留给数值大小。

## 红色克制

**默认不用红色。**

超出参考区间在临床上极常见且多数无临床意义（轻微偏高、生理波动、标本因素）。但红色对肿瘤患者是高强度焦虑信号——一张满屏标红的图会造成真实伤害，并驱使患者做出本不必要的行为（连夜挂急诊、自行停药）。

| 情形 | 用色 |
|---|---|
| 参考区间内 | 主紫。**不用绿色**——绿色暗示"好"，是隐性判断 |
| 超出参考区间 | 琥珀**描边**，不填充。只陈述"这点在区间外"这个客观事实，不渲染严重度 |
| 源报告自身标注危急值 | 红色。**唯一允许**——转述的是源报告的标记，不是我们的判断 |

`validate_chart_svg.py` 检查项 (e) 强制：红色出现次数不得超过 `--critical-count` 声明的源标危急值数量。

**趋势方向箭头默认关闭。** 向下箭头天然被读作"好转"，这是我们无权给出的判断。`direction` 字段仍产出（向后兼容），但不渲染成视觉箭头。

## 排版

- 正文 / 轴标签 ≥ **8pt**，数值标签 ≥ **10pt**，标题 11pt
- 通道 B 的 viewBox 单位 == 1pt，字号即真实 pt，不随容器缩放漂移
- **装不下就换行、移出、截断加 `<title>`，绝不缩小字号**。肿瘤患者中位年龄 60+，且会把图打印出来给医生看；lieflat 的 6.5px 下限是给屏幕上的运营 dashboard 设的，不可移植
- `validate_chart_svg.py` 检查项 (c) 强制 8pt 地板

## 卡片四件套

每张图固定四部分，缺一即验证失败（检查项 g）：

1. **标题** — 读图指引（这张图该怎么看、能不能信），不是结论也不是数字复读
2. **副标题 / 读图说明** — 单位、时间跨度、图例、可比性提示
3. **图** — inline SVG
4. **来源行** — 每个数字从哪来

## 几何诚实

- **柱与线不断轴**。长度 ∝ 数值是契约
- 面积编码用 `sqrt(v)` 换算半径，不拿数值直接当半径
- 时间轴按真实日历间隔，**不等距排列**。四次检验跨八年和跨四周不能长得一样
- 参考区间带被极端值压扁时，按最小高度显示并在说明里写明"不代表真实宽度"
- 每行量纲不同的对照图（如 `dumbbell`），**每行独立缩放**并声明行间长度不可比。共用一根轴会把 68 kg 和 132 g/L 放在同一尺度上，长度将失去意义

## 密度靠家具，不靠数据

临床序列通常只有 3–15 个点。稀疏数据只画点和一根底线必然寒酸。密度预算花在**无数据的结构层**上：导轨、rim 刻度、每 N 单位的立柱网格、账本横线、引线。

数据层保持诚实稀疏，**绝不用伪随机填充**（`chart_core.py` 里没有随机数发生器，这是刻意的）。

## 交互与动画

不做。理由不是技术限制：

- 患者会截图发家属群、打印给医生、转发给第二意见医生——零 JS 保证文件在这三处长得一模一样
- 患者不该被迫判断"我的病历文件里这段脚本安不安全"
- 交付走 Chrome→PDF 打印路径，canvas 会印成空白

`<title>` 提供的原生 tooltip 是唯一的交互，它在打印时自动消失，不影响静态呈现。
