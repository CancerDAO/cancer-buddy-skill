# 医疗资源数据源

## 可用来源

1. 卫生行政部门/监管机构的机构执业信息；
2. 医院或研究中心当前官方页面和官方预约系统；
3. ClinicalTrials.gov、WHO ICTRP、ChiCTR 等当前注册记录，用于核对研究地点和状态；
4. 支付方/医保官方页面，用于核对支付政策；
5. 机构直接书面或电话确认，记录确认日期和部门。

## 不作质量证据

医院排名、媒体榜单、论文数量、医生职称、协会头衔、患者点评和商业平台热度可帮助发现候选，但不能证明个体治疗质量或产生排序。

## 新鲜度

- 所有服务、医生出诊、试验状态、价格、等待时间和联系方式在输出时实时核验。
- 静态种子只用于生成查询，不得直接进入患者输出。
- 无法核验时标 `unconfirmed`，不根据历史页面或模型记忆补写。
- 记录直接 URL、页面/电话来源、访问日期和下一次复核日期。
