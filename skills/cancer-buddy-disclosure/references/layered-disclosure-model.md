# Layered Disclosure Model —— 分层披露，而非"全告"或"全瞒"

## 核心命题

披露不是一个事件（a moment），而是一个过程（a process）。把"告诉患者"想象成一个开关只有两档 —— 全告或全瞒 —— 是一个常见的思维错误，它让家属陷入"要么做冷酷的人，要么做善意的骗子"的二选一，然后通常选择后者，然后永远选不了前者。

更真实的模型是：披露有多个层级，每一层都可以由患者和家属共同决定**什么时候**、**到哪一层**、**以什么措辞**。

## 四个标准层级

### Layer 1 —— 基础诊断（basic-dx）

**内容**：患者有什么病，主要器官/部位，是不是"肿瘤"或"癌"，而不是含混的"增生"、"包块"、"肿物"。

**示例用语**：
- 充分层：「医生确诊是肺癌。」
- 克制层：「肺部长了东西，医生说是肿瘤，需要规范治疗。」
- 最低层（很多家庭的起点）：「肺里有个毛病，要做治疗。」

**转入第 2 层的信号**：患者开始问"是不是肿瘤"、"是不是癌"、"严重吗"；或治疗开始后身体反应明显（脱发、胃肠道反应），患者开始做自己的因果归因。

### Layer 2 —— 预后信息（prognosis）

**内容**：分期、大致生存期预期、治愈/控制/姑息的治疗目标定位。

**示例用语**：
- 充分层：「分期是 IV 期，医生说这是晚期，治疗目标是控制而不是根治。」
- 克制层：「医生说比较严重，但现在有药可以控制。我们先按治疗方案走。」
- 最低层：「医生说需要长期治疗，具体的情况医生还在评估。」

**为什么不能跳过**：如果患者被告知"是癌"但一直以为是早期可治愈，等到治疗无效时的心理冲击会远大于一开始就告知分期的情况。prognosis 层的信息决定了患者**怎么做生活决策**（工作、财务、关系、未了心愿）。

**转入第 3 层的信号**：患者开始问"我还能活多久"、"我会不会死"、"手术/化疗到底能不能治好我"；或治疗方案面临关键分叉（换线、加入临床试验、是否转姑息）。

### Layer 3 —— 治疗方案与参与决策（treatment-options）

**内容**：可选的治疗方案、各自的风险/收益/副作用/经济代价、为什么医生推荐某一方案，患者自己愿意接受哪些。

**示例用语**：
- 充分层：「现在有两个方案：方案 A 是化疗 + 靶向，控制期可能更长但副作用大；方案 B 是只做支持治疗，生活质量更好。医生推荐 A，但决定是你的。」
- 克制层：「医生说有两种治疗路线，各有利弊，我们一起听医生讲完你再决定。」

**这一层是"患者自主"真正落地的层**：患者不参与这一层，知情同意形式合法但实质缺失。后续出现并发症、经济压力、生活质量下降时，家属承担的内疚和冲突会更重。

**转入第 4 层的信号**：治疗线数耗尽、ECOG 恶化、症状负担加剧、患者主动表达"太累了"/"不想再治了"（先走 mind C-SSRS 排除抑郁，再判断是否为 informed palliative preference）。

### Layer 4 —— 终末期与姑息（palliative）

**内容**：当前治疗已无根治可能、可能进入缓和 / 安宁疗护阶段、死亡话题、预立医嘱、后事安排。

**示例用语**：
- 充分层：「医生说抗癌治疗已经没有太多选项，接下来重点是让你舒服一些。我们想一起和缓和医疗团队谈谈。如果你愿意，我们也可以谈谈你希望怎样度过这段时间。」
- 克制层：「医生建议换一种照顾目标，以让你更舒服为主。你怎么想？」

**这一层和 cancer-buddy-comfort 高度耦合** —— 实际上，comfort 模块在 `disclosure_state = suppressed` 且 `active_role = patient` 时会拒绝进入，正是因为"讨论缓和"本身就已经披露到 Layer 4。所以缓和的前置就是这一层的披露。

## 每层之间的转场脚本

**1 → 2**：「上次告诉你是肿瘤，你最近有没有想多问一些？医生这边也有更详细的信息，如果你想，我们可以一起听。」

**2 → 3**：「医生给了我们几个治疗方向，各有各的考虑。我想和你一起听一遍，然后一起决定。你对自己身体的感受最清楚。」

**3 → 4**：「这段时间治疗比较辛苦，效果也没有我们希望的那么理想。医生建议考虑换一种思路 —— 不是放弃，是把重心从"压下肿瘤"换成"让你舒服"。我们想听听你怎么想。」

**倒退 / 重访**：任何时候患者说"不想再谈了"，家属应**接受**并**记录**（"5 月 3 日患者表示暂时不想谈预后"）；不强推，但保留未来再谈的开放度。分层披露不是单向电梯。

## 反模式 —— 二元披露的典型失败

- **全瞒到底**：患者在治疗反应和身体退化中自己推断出真相，但不能公开谈，所有家庭成员都在演戏；患者孤立感最大化；终末期无法完成关系、财务、心愿相关安排。
- **一次性全告**：初诊日把 stage IV + 中位生存期 + 治疗失败可能性一次性倒出；患者进入急性应激反应；家庭气氛断崖；后续治疗配合度下降；有时触发抑郁/自伤。
- **家属"善意谎言"升级**：从"是炎症"到"是良性肿瘤"到"已经治好了"，每一层都是新的谎言；患者即便最初不知情，也在治疗反应中起疑；谎言规模越滚越大，最终崩盘时家属关系受损。
- **"患者不坚强"的预设**：家属以"患者承受不住"为由拒绝任何告知，但从未问过患者本人想知道什么。这通常是家属自己承受不住，投射到患者身上。

## 进展的观察信号（movement markers）

以下任一出现，意味着可以考虑向下一层推进：

- 患者连续 3 次以上问同一个高信息量问题（"我是不是癌"/"我还能活多久"/"是不是没救了"）—— 这不是随口说，是想知道。
- 患者主动提出未了心愿 / 财务安排 / 亲人关系修复 —— 已经在自己推断。
- 患者搜索病名、药名、方案名（家属看到搜索记录）—— 已经在自己找信息，家属此时不配合反而被动。
- 治疗进入关键决策节点（换线 / 入组 / 转姑息）—— 下一个决策 substantively requires 患者在场。
- 患者表达疲惫、放弃情绪 —— 先走 mind 排除抑郁，再判断是否需要向 Layer 4 过渡。

分层披露的艺术在于：**跟上患者，而不是带着患者**。患者往往已经走到了下一层，家属只需要把门打开。
