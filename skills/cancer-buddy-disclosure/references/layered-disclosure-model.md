# 分层沟通，而非分层隐瞒

分层的目的是按照患者的信息偏好、节奏和理解程度组织沟通，不是按家庭意愿长期隐藏诊断，也不是一套固定从“轻”到“重”的医学路线。

## 会谈流程

1. 确认患者希望知道多少、希望谁在场、是否需要翻译或其他沟通支持。
2. 先问患者已经理解到哪一步，再分小段提供事实。
3. 每段后用 teach-back 核对理解，允许暂停并约定继续时间。
4. 清楚区分已确认事实、尚待确认的信息、可选路径和个人价值。
5. 记录患者偏好及其变化；偏好可以随时修改。

## 不可使用的逻辑

- 不以年龄、工作安排、哭泣、焦虑或家属担心作为长期延迟告知的充分理由。
- 不声称披露本身会导致抑郁、自伤或治疗放弃；也不声称隐瞒能保护预后。
- 不把“积极治疗”和“缓和医疗”做成二选一。缓和医疗可以从诊断起与抗肿瘤治疗并行，重点是症状、生活质量、沟通和照护支持。
- 不由软件决定患者“不能/不宜知道”。疑似能力受损按 `capacity-and-surrogates.md` 转正式评估。

## 输出目标

输出应是给患者和临床团队的沟通计划：希望了解的主题、希望参与的人、待确认的问题、下次沟通时间和支持资源，而不是“披露层级得分”。
