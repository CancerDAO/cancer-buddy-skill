# 当患者自己突然问起 —— 家属脚本

> **Locale**：pivot 语和场景脚本为中文**语言范例**；按患者 `profile.json.locale` 出最终话术（见 SKILL.md `## Locale` + `../../cancer-buddy/references/i18n.md`）。三步反射（确认在问什么 → 诚实承认不确定 + 邀请同面对 → 按追问强度决定是否升层）的结构跨语言通用，措辞用患者 locale 重新生成。临床占位（`stage IV`、中位生存期数值、`XX 癌`）逐字保留。

最难的不是"要不要告诉"的家庭会议，而是患者在某个下午突然转头问："我是不是癌症？" / "我是不是要死了？"

此时，家属有三个常见失败模式、一个合理应对框架。

## 三个失败模式

1. **直接撒谎**：「不是，只是炎症」—— 短期关闭了对话，中期持续产生新谎言，长期被治疗反应揭穿。每一次重复这个谎言，你都在扩大它的规模。
2. **立刻全披露**：在病房走廊或家里客厅，突然把 stage IV + 中位生存期 + 治疗可能失败 一次性倒出来 —— 强度远超患者此刻可承受的；本意是"回应患者的问"，实际上是"家属自己扛不住信息了，借这个问题卸载"。
3. **转移话题 / 逃避**：「别想这些，好好休息」—— 表面回避，实际上也是一种谎言：它告诉患者"你的问题不值得被回答"。下一次患者不会再问，然后孤立感最大化。

## 合理应对框架：不撒谎 + 不强推 + 开门

核心原则：**不要制造新信息（谎言），也不要强制推进披露层级；但要把门留开**。

### 三步反射

1. **确认对方想问的是什么** —— 一句话问回去，争取 5-10 秒，不让自己条件反射回答
   - 「你现在最担心的是什么？」
   - 「你为什么这样问？」
   - 「你自己感觉是什么？」
2. **诚实地承认不确定性 + 邀请一起面对**
   - 「医生那边有些更详细的信息，我也还在消化。要不我们明天一起去问医生？」
   - 「这个问题我没办法一句话回答你。但你想知道什么，我都会尽量让你知道。」
3. **根据对方的追问强度，决定是否当下进入下一层披露**
   - 如果对方说"算了不说了，我就是随口问" —— 接受，不强推；但把这次问话记进 disclosure_history（信号）
   - 如果对方说"我想知道，你别瞒我" —— 这是明确的 desire-to-know 信号，可以当下转入分层披露的下一层（从基础诊断 → 分期，或从分期 → 治疗方案）

## 核心 pivot 语（可复用）

以下话术的共同结构是：**不否认 + 不一次性倾倒 + 给下一个接触点**。

- 「你说的这些我听到了。医生那边的详细情况，我想我们一起去听，可能比我一个人转述更清楚 —— 明天 / 后天 我们一起挂号 / 问诊，好不好？」
- 「你想知道什么我们一起面对。今天你想先问哪一部分？」
- 「这个问题我没法一句话回答。我可以告诉你我知道的，你想听几分？」
- 「你是不是自己心里已经有个答案了？说给我听听。」
- 「医生上次告诉我的，我没全告诉你，怕你累。但你如果想知道，我现在就说。」

## 常见具体场景脚本

### 场景 A —— 患者问："我是不是癌症？"

**最差回答**：「不是，别瞎想」
**次差回答**：「是，stage IV，中位生存期 8 个月」（过载）
**合理回答**：
> 「你为什么问？是医生说什么了，还是你自己猜的？......（听完）......医生确实告诉我是肿瘤。你现在想知道更详细的吗？还是我们先一起去医生那里，一起听他讲？」

### 场景 B —— 患者问："我是不是要死了？"

**最差回答**：「别胡说」
**次差回答**：「医生说中位生存期 8 个月」
**合理回答**：
> 「你最近是不是感觉特别累 / 特别难受？......（听完）......这个病确实严重，但没有哪个医生能说准什么时候。你现在想多问吗？还是你今天主要想说一下这种害怕？」

注意：这个问题背后常常是**孤立感**和**恐惧**，不是纯信息请求。先回应情绪，再回应信息。

### 场景 C —— 患者问："你们是不是瞒着我什么？"

**最差回答**：「没有啊」
**合理回答**：
> 「说实话，有一些事我们还没和你说完整，不是瞒你，是想挑一个合适的时机。你想现在谈，我们现在就谈。你想等一下，我们就等。但我不会永远瞒你 —— 这不对。」

承认家族的"尚未完全告知"是诚实的；它不等于"当下要全披露"，但把信息管控变成透明的协商。

### 场景 D —— 患者问第 3 次以上同一个问题

**信号**：重复问同一个高信息量问题 = 想知道，但之前的回答没满足。

**应对**：不要再用含糊的话推回去。这是一个应该进入下一层披露的明确时刻。可以说：
> 「你问过几次这个问题了，我想你是真的想知道。我之前没说清楚是因为我自己也在消化。现在我告诉你 —— ......」

然后给 Layer 2 或 Layer 3 的信息（看当前已披露到哪一层）。

## 要避免的具体措辞

- 「医生说没事的」—— 直接谎言
- 「你想太多了」—— 否定对方的情绪和认知
- 「你就听我们安排」—— 剥夺自主性
- 「等你好一点再说」—— "好一点"可能永远不来，这是无限期推迟
- 「这么大岁数了还操心这些」—— 年龄歧视，且否定患者的人格

## 要常用的具体措辞

- 「你想知道什么？」
- 「你现在最担心什么？」
- 「我们一起面对」
- 「我不会瞒你」
- 「今天不想谈也没关系，想谈了再说」

## 回到家后，写进 disclosure_history

每一次这种"突然问起 + 家属应对"的事件，都写进 `profile.disclosure_history[]`：

- 日期
- 是谁问的（患者本人）
- 问了什么
- 家属如何回应
- 当前推断的 `disclosure_state`（是否有升层）
- 下一步打算（是否约了医生、是否打算下周进入下一层披露）

这些记录是下一次家庭会议和下一次问诊的依据。
