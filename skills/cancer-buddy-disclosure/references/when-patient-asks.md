# 当患者主动询问病情

患者明确提问时，不用家属设置的 `suppressed` 状态做平面拒绝，也不撒谎、转移或提供虚假保证。

## 回应顺序

1. 承认问题的重要性，并询问患者现在希望了解概况还是详细内容、是否希望家人/医生在场。
2. 只使用可追溯的正式资料；来源冲突时展示冲突并说尚未核实。
3. 对诊断、分期、疗效、治疗选择和预后，不由 skill 下个人结论。帮助患者把正式报告带给主诊医生逐项核对。
4. 如果患者现在就明确要求查看自己的记录，在完成身份与访问授权后，不因家庭偏好永久遮蔽；对可能造成意外冲击的内容先提示并提供临床支持路径。
5. 记录最少必要的 `information_preference`，包括患者希望知道的范围、参与者和时间；不要记录不必要的情绪标签或家庭评价。

## 示例

> 你有权表达自己希望了解多少。我可以先把资料里明确写出的内容和仍有冲突的地方分开整理，但不会替主诊医生重新诊断或判断预后。你希望先看概况，还是逐份和医生核对？

若患者的请求涉及紧急症状，先执行急诊/主诊团队升级，不让披露流程延误治疗。
