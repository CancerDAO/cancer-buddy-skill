# Phase 1：来源保真的 OCR/转录

目标是生成可复核 sidecar，不是让 LLM 成为唯一字符真值。

## 流程

1. 保存原文件、内容 hash、文件元数据和不可变 `source_id`。
2. 优先使用适合文档类型的确定性 OCR/表格/条码/DICOM/PDF 文本提取器，并保存引擎、版本、语言和原始输出。
3. LLM 只做版面重建、候选纠错和语义标注；任何改动同时保留 `raw_text`、`proposed_text`、理由和位置。
4. 对姓名/标识、日期、药名、剂量、频次、实验室数值、单位、参考范围、分期、变异、VAF 和 accession 执行第二次独立读取；不一致则标 `needs_human_review`。
5. 低质量、截断、遮挡、手写或单位不清的字段写 `unreadable/uncertain`，不猜。
6. 数字表格保留行列、脚注、检测方法和每次报告自己的参考范围。

## 脱敏

文本 sidecar 按最小必要原则生成脱敏派生版本，同时保存授权范围内的原始文件。PII 遮蔽不得改变药名、剂量、日期、编号后缀、分子变异或单位。跨境/共享前另行评估图像级和元数据脱敏；不能声称 sidecar 脱敏等于匿名。

## 输出

每个字段包含 source span、OCR 引擎、抽取置信度、复核状态和源文件 hash。高风险字段未通过双重核对时不得进入患者摘要中的已确认值。
