# 补剂的诚实评估

> **Locale**: every `诚实回答` reply template and the closing 回答模板 below are the **source string table** — render the localized equivalent in `profile.json.locale` at output time per `../../../references/i18n.md` §5. Supplement standard names (灵芝孢子粉 / 冬虫夏草 / 人参 / vitamin C …), drug names and `<current_therapy>` placeholders stay verbatim across locales.

患者和家属会问很多补剂——你要能给诚实、不带卖货气的评估。

## 原则

- **A 级证据（大规模 RCT）才能叫"有效"。** 几乎没有口服补剂达到这个等级的抗肿瘤证据。
- **"有体外/动物研究" ≠ 对患者有效。** 说清楚这个差别。
- **补剂 ≠ 食物。** 当作食物吃（适量人参炖鸡）和当作药吃（每天灵芝孢子粉胶囊）是两件事。
- **明确利益冲突。** 很多推荐者卖东西——告诉患者这层。
- **尊重选择。** 患者若坚持要补，在不干扰主治疗的前提下，给出"怎么吃最不影响疗效"的建议。

## 常见问题

### 灵芝孢子粉

- **证据**：小样本中国研究提示免疫调节作用；缺乏大样本 III 期 RCT 证明改善生存
- **风险**：与 TKI 类药物可能影响代谢，与抗凝药合用增出血风险
- **诚实回答**：`循证证据还不足以证明抗肿瘤疗效。如果你真的想吃，建议避开 TKI / 华法林服药时间至少 2 小时，食物量级短期使用应该安全。不要替代主治疗。`

### 冬虫夏草 / 虫草花

- **证据**：提取物在细胞和动物模型有免疫活性；临床证据弱
- **诚实回答**：`类似情况。野生冬虫夏草价格昂贵——不是性价比之选。如果追求免疫营养，规律睡眠和蛋白摄入更重要。`

### 人参

- **证据**：美国 Ginger Ginseng 研究对化疗相关疲劳有中等证据改善；传统应用对精气神补益
- **风险**：抗血小板；高血压；手术前 7 天停
- **诚实回答**：`对化疗疲劳可能有帮助——西洋参（非红参/高丽参）更对症。手术前 7 天停。服药期尤其抗凝药需告知医生。`

### 维生素 C 高剂量口服 / 静脉

- **证据**：口服大剂量无抗肿瘤证据；静脉 vitC + 化疗组合在部分研究有协同但标准治疗尚未采纳
- **风险**：免疫治疗期理论担忧；大剂量静脉 vitC 可致肾结石/溶血
- **诚实回答**：`常规剂量食物来源没问题。高剂量补剂不要自己加——如确要尝试静脉 vitC，只在有经验的正规医院，并告知所有主诊医生。`

### 蛋白粉（乳清/植物）

- **证据**：蛋白不足时的补充方式，非特殊抗肿瘤
- **诚实回答**：`正常。如果你吃不下肉蛋奶，蛋白粉是合理补充。乳清蛋白优于纯大豆（BCAA 完整）。糖尿病或肾功能不好需具体定量。`

### 奇亚籽/藜麦/牛油果类"超级食物"

- **诚实回答**：`它们是好食物，但没有抗癌专利。把它们当作营养均衡的一部分就可以，不要神化。预算有限的话，国产荞麦、小米、白菜、番茄同样有用。`

### 生酮饮食 / 间歇性禁食抗癌

- **证据**：部分脑胶质瘤早期研究显示生酮可能有协同效应；其他癌种证据不足；临床广泛采纳尚早
- **风险**：体重丢失太快、营养不良
- **诚实回答**：`除非主治医生和营养师共同制定方案，不要自行尝试。尤其化疗期自行禁食可能削弱治疗耐受。`

### 左旋咪唑 / 氯喹 / 伊维菌素 等"老药新用"

- **诚实回答**：`网上有很多基于体外研究的热门话题。但没有任何一种达到"患者应该自行服用"的证据门槛。非常不建议自行使用。`

### 中医治疗配合化疗

- **证据**：部分地区（中医药研究所）有辅助缓解毒性的研究；整体循证等级弱
- **诚实回答**：`如果想配合，找正规中医院的中西医结合科，让中医和主治医生知道彼此的方案——关键是避免冲突。不要同时找多个民间中医喝多套汤药。`
