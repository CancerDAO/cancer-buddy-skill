# 补充剂回答边界

## 不可输出的结论

- 不声称任何食物、维生素、矿物质、草药或特殊饮食可以治疗、控制或预防癌症复发，除非当前适用指南明确支持该具体用途。
- 不把体外、动物、小样本或替代终点研究写成患者获益。
- 不给灵芝、人参、虫草、vitamin C、蛋白粉等通用“安全剂量”“安全时长”或“错开几小时”建议。
- 不声称某一种蛋白来源普遍优于另一种，也不凭白蛋白、贫血或疲劳单项结果推荐补剂。
- 不把“天然”解释为安全，不把“食物量”自动解释为无相互作用。
- 不为生酮、间歇性禁食、静脉 vitamin C 或老药新用提供自行尝试路径。

## 安全回答工作流

1. 记录产品全名、品牌、配料表、单份含量、实际剂量、频次和用途；复方产品必须逐成分核对。
2. 询问当前治疗、其他药物、肝肾功能问题、出血风险、手术计划和过敏史，但不据此自行判定安全。
3. 按 `drug-food-interactions.md` 实时核对每种成分与具体方案。
4. 说明证据类型和直接性；没有临床获益证据时明确说“尚不能证明”。
5. 在开始、继续或停用补剂前，建议把产品照片/配料表交肿瘤药师、主诊医生或注册营养师核对。

## 模板

> 目前没有足够、直接且适用于你这个治疗场景的证据证明 `<product>` 能治疗癌症或改善生存。它的成分可能与药物或共病有关联；我不能根据模型记忆判断安全，也不能给通用错开时间。请把完整配料表和当前用药清单交给肿瘤药师/主诊团队核对。在核对前不要用它替代治疗或自行改变处方药。
