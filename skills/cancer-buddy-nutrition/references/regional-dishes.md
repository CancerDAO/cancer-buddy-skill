# 各地家常菜替换示例

可替换的例子，不是固定食谱；份量按个人计划。先问患者平时吃什么、能耐受什么。

| 类别 | 北方/家常 | 江南/南方 | 川湘 | 粤菜/客家 |
|---|---|---|---|---|
| 软主食 | 软米饭、烂面条、小米粥 | 软饭、米粉、白粥 | 软饭、米线 | 粥、软饭、河粉 |
| 蛋白来源 | 熟鸡蛋、豆腐、炖鱼、鸡肉 | 蒸蛋、豆腐、清蒸鱼虾 | 炖肉、蒸蛋、豆腐 | 白切鸡（熟透）、蒸鱼、蛋羹 |
| 蔬菜 | 炖白菜、西葫芦、冬瓜 | 清炒时蔬（炒软）、丝瓜 | 少辣的炖菜、南瓜 | 滚汤菜、节瓜、菜心 |
| 按症状调整 | 做软、少油、分小餐 | 不吃生腌醉虾醉蟹；酸味按耐受 | 口腔溃疡时少辣少麻 | 药膳汤先把每味药材拿去核对相互作用 |

## 按症状的一般调整

| 症状 | 可以试 |
|---|---|
| 没胃口 | 少量多餐、手边放小零食、先吃蛋白质 |
| 恶心 | 温凉的、气味淡的食物；饭前饭后别大量喝水 |
| 口腔溃疡、吞咽痛 | 软、烂、不烫、不酸不辣；用吸管 |
| 腹泻 | 少油少粗纤维，补液；持续或伴发热联系团队 |
| 便秘 | 按耐受增加水分和活动；用药前问团队 |

姜、柠檬、番茄、药膳、蛋白粉等不写成"普遍有效"。
