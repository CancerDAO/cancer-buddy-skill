# Case Summary Template — 病例总结模板

共享模板。所有生成病例总结的 sub-skill 都读这里，不得自己另起一套。
当前消费者：`cancer-buddy-organize`（Phase-2 Synthesis Worker Step 6）。

---

## 一、双模式输出规范

| 模式 | 文件名 | 篇幅 | 受众 |
|---|---|---|---|
| **简要总结** | `case_summary_brief.md` | 1–2 页（≤ 800 字正文） | 接诊医生、快速回顾 |
| **详细总结** | `case_summary_detailed.md` | 8–10 页（不设字数上限，但拒绝堆砌） | MTB 会议、二次意见、出院小结附件 |

**简要版**包含：全部 7 个模块（在包含关键判断指标（标志物）的基础上，重点关注发生**变化**的部分[指标变化、治疗行为、转移情况]） + 未解决问题清单。

**详细版**包含：全部 7 个模块 + 附录（信息来源索引、未解决问题清单）。

两份文件在同一次 organize 中同时生成，路径：
```
patients/<patient_code>/case_summary_brief.md
patients/<patient_code>/case_summary_detailed.md
```

## 二、七大模块规范

### 模块 1 ｜ 基本信息 Basic Demographics

**必写字段：**
- 姓名 / 年龄 / 性别
- ECOG 体能评分

**条件写字段（按癌种决定，见下表）：**

| 字段 | 写入条件 |
|---|---|
| 吸烟史 | 只有肺癌（影响腺癌 vs 鳞癌预判、EGFR 突变概率）；胃肠道癌才写 |
| 既往史 | 心功能不全（影响蒽环类）、自身免疫病（影响免疫治疗）才写；其余既往史按临床相关性判断 |
| 家族史 | 默认**不写**；仅在已知遗传综合征（BRCA、Lynch、MEN 等）或家族史直接触发了本次基因检测决策时才写 |
| 体重 / BMI | 需要基于体表面积计算化疗剂量时写 |

**ECOG 来源优先级：**
1. 主治医生查房记录或护理评估（注明"医生评估"）
2. 无来源 → 向患者/照护者索取自评，写作 `ECOG X（患者自评，待医生核实）`，并在 `review_flags` 里标 🟡 yellow

**简要版**：只写姓名、年龄、性别、ECOG；其余按需一行带过。

### 模块 2 ｜ 病情概要

**必写条目：**

```
- 确诊时间：YYYY-MM
- 原发部位：[器官/亚部位]
- 病理类型：[腺癌 / 鳞癌 / 小细胞 / 其他]
- 分化程度：G1 / G2 / G3（如病理报告有）
- 分期：[分期系统名称 + 具体分期]（例：AJCC TNM 第 8 版，pT3N2M1a，IV 期）
- 初诊 or 复发？
- 转移部位：[部位列表] or 无远处转移
- 目前治疗状态：[一线 / 二线 / 三线+] [方案名] 第 X 周期
```

**数据来源（优先级见§四）：**

| 信息 | 首选来源 |
|---|---|
| 病理类型、分级 | 病理报告 |
| T/N/M 分期 | 影像报告 + 病理报告综合 |
| 切缘状态（R0/R1/R2） | 病理报告 |
| 手术所见 | 手术记录（Operative Note） |

### 模块 3 ｜ 分子检测与标志物

**通用指标（适用所有实体瘤）：**
- 免疫组化（IHC）：Ki-67、PD-L1（TPS% / CPS 评分）、MMR 状态（MLH1 / MSH2 / MSH6 / PMS2）
- 基因检测（NGS）：TMB（肿瘤突变负荷，单位 mut/Mb）、MSI 状态（MSS / MSI-L / MSI-H）
- HER2 状态（乳腺、胃、肺等）

**癌种特异指标：**

| 癌种 | 必看标志物 |
|---|---|
| 肺腺癌 | EGFR / ALK / ROS1 / KRAS G12C / MET ex14 / RET / BRAF V600E |
| 肺鳞癌 | FGFR1 扩增 / KEAP1 / STK11 / EGFR（低频但存在） |
| 乳腺癌 | ER / PR / HER2（HR 状态）/ BRCA1/2 胚系 / PIK3CA |
| 结直肠癌 | KRAS / NRAS / BRAF V600E / MMR-IHC / MSI / HER2 |
| 肝细胞癌 | AFP（基线）/ HBV DNA 定量 / HCV 状态 / Child-Pugh 分级 |
| 黑色素瘤 | BRAF V600E/K / NRAS / NF1 / cKIT |
| 胃癌 | HER2 FISH / PD-L1 CPS / EBV 原位杂交 / FGFR2 扩增 |
| 胰腺癌 | BRCA1/2 胚系 / KRAS / CDKN2A / SMAD4 |

**数据来源：** 病理报告（分子病理附件）

**写作格式：**
```
EGFR L858R 突变（VAF 42%）—— 来源：2024-03 燃石 NGS（Foundation One 面板）
PD-L1 TPS 60%（22C3 抗体）—— 来源：2024-01 病理报告
MMR 完整（MLH1+/MSH2+/MSH6+/PMS2+）—— 来源：2024-01 IHC
```

### 模块 4 ｜ 影像学评估摘要

**必须总结（不抄原文，提炼关键数字）：**
1. 原发灶大小（最大径，cm）
2. 区域淋巴结（受累站点数量 + 具体站点）
3. 远处转移（部位、数量、代表性病灶大小）
4. 与前次影像相比的**变化趋势**（新发 / 缩小 / 增大 / 进展 / 稳定，注明对照日期）

**写作格式：**
```
2026-04-15 PET-CT（北京 XX 医院）：
  - 原发灶：右肺上叶 2.3cm（前次 2025-12 为 3.1cm，缩小 26%）
  - 淋巴结：纵隔 4R、7 组，最大 1.4cm
  - 转移：肝 S5 单发 1.8cm（与前次持平）；无脑转移
  - 整体评估：部分缓解（PR，RECIST 1.1）
```

**数据来源：** CT（胸 / 腹 / 盆）、MRI（脑、肝、骨髓）、PET-CT、骨扫描

### 模块 5 ｜ 实验室指标摘要

**不列全部化验值**，只提炼有临床意义的（异常值 + 影响治疗决策的关键值）：

| 类别 | 关注指标 | 临床意义 |
|---|---|---|
| 血常规 | WBC、ANC、Hgb、PLT | 能否耐受化疗、是否需要 G-CSF |
| 肝功能 | ALT / AST（× ULN）、总胆红素、白蛋白 | 药物代谢、肝毒性评估 |
| 肾功能 | Cr、eGFR | 铂类剂量调整 |
| 肿瘤标志物 | 按癌种（CEA、CA19-9、CA125、AFP、PSA） | 基线 + 随访变化趋势 |
| 凝血 | PT / INR | 手术前、肝癌患者 |
| 特殊 | LDH（淋巴瘤/黑色素瘤）、β-HCG/AFP（生殖细胞瘤）、甲状腺功能（用免疫治疗时） | — |

**写作格式（只写异常值和关键值）：**
```
2026-04-18 血常规：ANC 1.2×10⁹/L（↓，低于化疗阈值 1.5）；Hgb 98g/L（↓）；PLT 正常
2026-04-18 肝功能：ALT 82 U/L（2.1× ULN）；白蛋白 32g/L（↓）
2026-04-18 CEA 45.2 ng/mL（较上次 2025-12 的 67.8 下降 33%）
```

### 模块 6 ｜ 治疗史

**按时间轴叙述，每一线一个段落：**

```
[线别]  [时间区间]  [治疗方案 + 剂量]  [周期数 / 总剂量]
疗效：[RECIST 评估结果 or 影像/标志物变化描述]
停药原因：[进展 / 毒性（描述具体毒性）/ 手术 / 患者意愿 / 其他]
```

**示例：**
```
一线  2023-12 → 2025-08  奥希替尼 80mg QD
      共 20 个月。最佳疗效 PR（靶病灶缩小 32%，2024-03 CT 确认）。
      停药原因：2025-08 PET-CT 脑转移新发进展（RECIST PD）。

二线  2025-09 → 至今  卡铂 AUC5 + 培美曲塞 500mg/m² q21d
      目前完成 4 周期。疗效评估：SD（靶病灶较基线缩小 8%，2026-01 CT）。
      剂量调整：第 3 周期培美曲塞减量 20%（Grade 2 中性粒细胞减少）。
```

**必须包含：**
- 手术（术式、切除范围、切缘 R 分级）
- 放疗（部位、总剂量 Gy、分次数、技术如 IMRT / SBRT / 质子）
- 化疗、靶向、免疫（方案名、周期/疗程、剂量调整原因）
- **重要毒副反应和住院事件**不得省略
- **患者对前线治疗的反应**即使是阴性结果也要写

**数据来源：** 化疗医嘱（长期 / 临时）、放疗计划报告、门诊随访记录、出院小结

### 模块 7 ｜ 治疗路径总结

**仅供参考，不做临床推荐，不替代 MTB / 主诊医生。**

必须包含以下结构：

```
## 待解决问题
- [ ] [等待哪项检查结果？预计何时回报？]
- [ ] [还有哪个数据空白影响决策？]

## 当前治疗状态
[用一句话描述现状：在第 X 线 Y 方案 Z 周期，下次评估日期是……]

## 下一步可探索方向（非推荐）
- 继续现方案？（需说明评估节点）
- 换线考虑（需根据现有 profile 列出潜在方向，加"需 MTB 评估"标注）
- 临床试验？（转 find-care 技能）
- 跨境二次意见？（转 second-opinion 技能）
- 姑息 / 缓和医疗讨论？（转主诊医生）
```

## 三、缺失字段处理规则

当某字段在病历中找不到时，按三步处理，**不得静默跳过**：

```
第一步：确认"找没找对地方"
  → 重新从 ocr/ sidecars 搜索，包括叙述性文字中的隐含信息
  ↓ 仍找不到
第二步：判断属于哪种缺失类型（见下表）
  ↓
第三步：按对应方式写入总结
```

| 缺失类型 | 判断标准 | 总结中写法 | 是否触发 review_flag |
|---|---|---|---|
| 报告存在但 OCR 未提取到 | sidecar 文件存在，但字段为空 | — 先尝试重新定位；若仍失败 → 标注"见原始报告 `<文件名>`" | 🟡 yellow |
| 已开单，结果未回 | 有"已送检"或医嘱记录，无结果单 | `PD-L1：Pending（已送检，待回报）` | 🟢 green |
| **应做但未做** | 临床上该有此检测，但无任何记录 | **`EGFR 突变状态：未检测，建议完善`** | 🔴 red（影响下游 find-care / MTB 的为 red） |
| 客观无法获得 | 患者转诊，原始报告未带来 | `XX 病理报告：未取得（原就诊医院：XX，可联系调阅）` | 🟡 yellow |

> **核心原则：缺失的重要信息必须显性化。"未检测"和"阴性"是两回事，必须区分。**

## 四、信息冲突处理优先级

当多个来源对同一字段有不同记录时，按以下优先级采信，**并在总结中注明冲突来源**：

```
病理报告 > 分子标志物报告 > 影像报告 > 门诊 / 入院记录叙述 > 症状描述
```

冲突写法：
```
分期：pT3N2M1b（出院诊断证明，2024-07）
      [注：入院记录叙述为"IV 期"，病理报告写作 pT3N2M1a，采信病理报告值 pT3N2M1a；
       冲突已标入 review_flags RF-003]
```

## 五、写作规范

- 用**标准医学术语**，缩写首次出现写全称（ECOG = Eastern Cooperative Oncology Group）
- **每个关键数字必须能追溯到来源报告**（在详细版里，每行数据后标来源）
- 按**时间顺序**叙述治疗经过（模块 6 尤其严格）
- 保持**客观中性**语言——描述事实，不评价方案好坏
- 不抄整段影像报告原文
- 不罗列所有化验值（只列异常值和关键值）
- 不加入**未经证实的推测**
- 不省略**重大毒副反应和住院事件**
