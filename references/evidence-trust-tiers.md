# 证据信任分级（全局共享合同）

本文件规定 cancer-buddy 全部 skill 与 sub-skill 在**回答前**如何决定「哪一条信息可以直接用、
哪一条必须 answer-time 重新核、哪一条要先跑一次廉价探针」。

**分层的轴是「事实的半衰期」，不是「证据的强度」。** 一篇 RCT 比一份出院小结「证据强」，
但出院小结上那条「体温≥38.0℃ 立即联系管床医生」的半衰期可能只到下次换方案为止；
反过来「HER2 是一种受体酪氨酸激酶」这句话证据等级不高，却几十年不变。
按强度分层会让产品去重查不会变的东西，同时放过会变的东西——这正是要避免的失败。

本文件只回答「要不要重新核」。**要不要引用、引用长什么样**由 `citation-format.md` 决定；
**哪些 claim 需要人工复审生命周期**由 `clinical-content-governance.md` §1 决定；
**核不到时如何失败关闭**由 `safety-guardrails.md` 的 no-silent-snapshot 红线决定。
本文件不放宽上述任何一条：S 层只是「不必重复联网」，不是「可以不引用」，更不是
「可以由模型凭记忆合成」。

## 0. 三层的含义（两条轴共用同一套字母）

| 层 | 含义 | 回答前的动作 |
|---|---|---|
| **S**（stable） | 半衰期以年计的稳定事实 | 直接用，不重新联网 |
| **V**（volatile） | 会在数周至数月内翻面的事实 | **永远 answer-time live 核**，核不到就标未确认 |
| **D**（drift / 仲裁） | 不确定它变没变 | 先跑**廉价探针**判断是否升级为全量核验 |

S / V / D 是**处置层**，与患者可见的四类来源标签（`〔档案〕〔资料库〕〔联网〕〔文献〕`）
正交。**分层术语一律不出现在患者可见输出里**（`citation-format.md` §1）。

## 1. 轴一：外部知识的半衰期

| 层 | 属于这一层的内容 | 处置 |
|---|---|---|
| **S** | 稳定概念与机制（受体、通路、药物作用机制）；疾病定义与自然史；分期系统的定义本身；检查项目「是什么、怎么做、为什么做」；症状与照护的一般常识 | 可直接作答依据。命中本地库（L1/L2/L3）即用，标出出处与版本，不必再联网 |
| **V** | **五类时效敏感断言**：① 药品**获批状态**与适应症 ② **医保/报销**目录与准入 ③ **临床试验在招**状态 ④ **指南版本**与其中的推荐内容 ⑤ **中心/医生名单**与开展资质。另加：紧急阈值等会随方案变的操作性规定 | **永远 live**。**无论本地是否命中都要 answer-time 实核一次**（`safety-guardrails.md` no-silent-snapshot）。本地命中的作用是把盲搜变成拿着具体方案名/药名/线次去精准核验，不是免检 |
| **D** | 「本地库里那份指南是不是已经出新版了」「这个试验上次看还在招」等**无法先验判断变没变**的情况 | 每次回答跑一次**廉价探针**（查版本号/发布日/状态字段，不拉全文）→ 探针发现更新、矛盾、或本地快照明显陈旧 → **升级为全量 live 检索**；探针每次跑，全量按需 |

**两条加码**

- **承重度**：整个回答的结论就挂在这一条上（换线依据、急诊阈值、入组资格的决定性条件），
  即便它落在 S 层，也 live 复核一遍。承重的东西不吃「一般不会变」这种概率。
- **快照永不冒充当前**：本地库（含 L1 结构化清单）是**带 `as_of` 的快照**。呈现时必须显示
  数据截止日与官方入口；快照 age 越老，V 层越危险。核不到就说核不到，不用模型记忆兜底。

## 2. 轴二：患者档案自身的半衰期

这一轴是 cancer-buddy 特有的：外部知识会过期，**患者自己的档案同样会过期**，而且过期得更快。
把 2026-05 的出院小结当成「现在」来答，和把 2019 版指南当成「现行」来答，是同一种错误。

| 层 | 档案里属于这一层的字段 | 处置 |
|---|---|---|
| **S** | 病理诊断与分型、**胚系**变异、既往手术记录、既往用过的方案清单（历史事实）、过敏史、出生年份 | 直接用。这些是**已经发生的事**，不会因为时间流逝而改变（只会被新报告**补充**，不会被推翻） |
| **V** | **当前方案**与**治疗线次**、当前用药与剂量、体重/体表面积、ECOG、最近一次实验室值、是否在住院、经济与可及性状况、联系与照护安排 | **不当成"现在"直接用**。引用时必须显示该字段的报告日期，并提示「若之后有变化请指出」。跨越了一次方案变更的 V 字段视为**可能失效**（`treatment_lines.json` 变动即触发） |
| **D** | 「档案是不是已经不是最新的」 | **每次回答跑一次廉价探针**：比对 `update_log.json` 的 mtime / 最后一条写入时间与**本次问题所涉字段**的最后更新时间；若问题落在 V 字段而该字段的来源报告已明显早于最近一次档案更新（或档案本身长期未更新）→ 先问一句「有没有新报告/换过方案」，再作答 |

**探针是廉价的、每次都跑的**：读 `update_log.json` + 相关域 JSON 的 `source_refs[]` 日期即可，
不需要重新读全部档案，也不触发联网。

**第一方指令的失效**：主诊团队对本人的书面交代（出院小结上的阈值、随访间隔、联系电话）
属于 V 层。引用时**必须同时给出日期与它当时对应的治疗线**，并与 answer-time 的公共来源
**并列呈现**——第一方指令回答「我该怎么做」，公共来源回答「一般怎么规定」，两者不互相替代。

**不给 organize 产物加 `trust_tier` 列。** 档案字段全部是 `source_reported` 层，
半衰期在**消费侧**由 `source_refs[]` 的报告日期 + `update_log.json` 推出即可；
加冗余列会与既有的 `provenance_layer` 语义打架。

## 3. `trust_tier` 由位置硬判，LLM 无权提级

`index.json` 里的 `publisher` / `version` 全是**用户可写的自我声明**。一份营销册配一条自称
NCCN 的条目，就会以权威格式被引用。因此信任层**按路径前缀硬判**，不看内容自述、不看模型判断。

| 位置 | `trust_tier` | 可以用来做什么 |
|---|---|---|
| **L1**：skill 自带库（`skills/cancer-buddy/references/library/`，我们审过、随 git 分发） | `curated` | 可作答案依据（仍受 §1 的 V 层 live 约束） |
| **L2**：用户全局库（`$CANCER_BUDDY_GUIDELINES` 或 `~/CancerDAO/library/`） | `user_supplied` | 可作**骨架、术语基底、引用锚**；**五类时效敏感断言不作最终依据**，必须并列 answer-time 核验结果 |
| **L3**：患者专属库（`<patient_dir>/library/`） | `user_supplied` | 同上 |
| `<patient_dir>/14_患者自管补充/` | `lead_only` | 只作线索，**不作任何临床结论的依据**，不得进入临床结构化 JSON 的 `source_refs` |
| `<patient_dir>/99_无关文件/` | 不进检索链 | — |

**硬约束**

- 分级是**路径前缀判断**，不是一段 prompt。模型**不得**因为「这份 PDF 看起来就是真 NCCN」
  把 L2/L3 条目提级为 `curated`，也不得因为条目自称权威而跳过 V 层 live 核验。
- 提级只有一条合法路径：内容被我们审过并**移动到 L1 目录**，随 git 分发。
- 降级永远合法：任何时候把一条 `curated` 当 `user_supplied` 用都是安全的。
- 未在 `index.json` 登记的文件、路径含 `..`、或经 realpath 后落在库根之外的文件，
  **一律不进检索链**（不是降级，是不读）。

## 4. V 层必须落盘抓取产物，不能只写一个日期

**日期是模型能写的字符串，落盘的原始记录不是。** 一条 V 层结论要被当作「已核」，
必须同时满足：

- `live_checked_at`：实际发起核验的日期（不是「今天」的推断，也不是复制来的旧值）
- **落盘的抓取产物**：这次核验取回的原始记录（源 URL + 取回时间 + 关键字段原文/截取），
  写进本次运行的产物目录，可被第三方复核
- 源标识：直接 URL 或注册号/条目号，指向**一手来源**（不是搜索结果摘要、不是聚合站）

**只有 `live_checked_at` 而没有落盘产物 = 视为未核**，按核不到处理：标「需现场核实」，
给出患者可自行核对的官方入口，不把它当现行依据。

复用缓存的抓取产物同样按层处置：S 直接复用；V 按 age 强制重核（几个月前的「在招」
极可能已经关组）；D 跑增量探针。

## 5. 调用方

任何面向患者输出的子技能在作答前都要过这两条轴。落地位置：

- 检索命中后、动笔前，先判本次问题涉及的断言落在哪一层
- V 层未核成功 → 走 `safety-guardrails.md` 的失败关闭，不降级到模型记忆
- 引用渲染仍按 `citation-format.md`，**不把 S/V/D 或 `curated`/`user_supplied` 写给患者看**
